## 16 พฤศจิกายน 2569 · เฟส 1: ตัดสิ่งที่ไม่ใช่การจดงานออก · แยกแถว cloud (คง 0A0)

- **ไม่โหลดแล้ว 66 ไฟล์**: โซเชียล · ฟีด · แชท · ห้องการบ้าน · หัวข้อ · กลุ่มเรียน · ห้องของฉัน · กระดานอันดับ · อีเวนต์ · ข่าวสาร · Halloween ทั้งชุด · ระบบโทเคน/ร้านค้า · กาชา · เกมฉลอง · 3D (ไฟล์ยังอยู่ ไม่ได้ลบ)
- ถอดแท็บแชท AI (น้องฮูก) และปุ่ม "ถามน้องฮูก" · คง `sai.js` ไว้เพราะเป็นจอแผนวันนี้ ไม่ใช่แชท
- คงไว้: ตัวจัดลำดับงาน · โหมดโฟกัส · ตารางเรียน/ช่องว่าง · LINE · ตัวเชื่อม Classroom · สแกนใบงาน · แจ้งเตือน · รายงานปัญหา · ลบบัญชี
- `clear.css` ซ่อนปุ่มที่พาไปฟีเจอร์ที่ถอด · `clear.js` ส่งทุกทางเข้าจอที่ถอดกลับหน้าแรก และกันฟังก์ชันที่ไม่มีแล้วไม่ให้แอปพัง
- **ซิงก์ cloud ใช้ตาราง `user_state_clear`** แทน `user_state` ของแอปหลัก — ต้องรัน `supabase/migrations/20261116120000_user_state_clear.sql` ก่อน · ยังไม่รัน = ใช้ในเครื่องอย่างเดียว ไม่เขียนลงแถวของแอปหลักเด็ดขาด
- วัด (Chrome จำลอง CPU ช้า 4 เท่า · งาน 60 ชิ้น · ไม่ใช่มือถือจริง): ไฟล์ที่โหลด 132 → 56 · เปิดแอป 4.2 → 2.3 วิ · สลับแท็บเฉลี่ย ~520 → ~210ms · กฎ CSS 9,027 → 6,564
- ทดสอบ: SQL กับ Postgres จำลอง 6/6 (เห็นแค่แถวตัวเอง · rev เดินเอง · ลบบัญชีแถวหายตาม) · ไม่มีตาราง = ปิดซิงก์เงียบ ไม่ยิงซ้ำ · ผู้ใช้ใหม่/ผู้ใช้มีงาน เปิดทุกแท็บ ติ๊กงาน แผ่นเพิ่มงาน ตั้งค่า ไม่มี JS error · ยังไม่ได้ลองกับ Supabase จริงและมือถือจริง

## 16 พฤศจิกายน 2569 · Student OS Clear 0A0 “Flimsy” · เริ่มเวอร์ชัน clear (โค้ดจากแอปหลัก 1C62)

- ตั้งเลขรุ่น `0A0` ชื่อรุ่น “Flimsy” (`APP_VERSION` · `APP_CODENAME` ใน app.js · `CACHE` ใน sw.js) · ป้ายรุ่นในแอปขึ้นว่า "Student OS Clear 0A0 “Flimsy”"

- คัดลอกแอปหลักทั้งชุดจาก main (`aaf6d9d` · รวม PR #102) มาไว้ที่ `clear/`
- **ข้อมูลในเครื่องแยกจากแอปหลัก**: คีย์ `studentos.alt.*` → `studentos.clear.*` (รวม legacy/shortcutDraft/desktop sidebar) · เปิดครั้งแรก = แอปเปล่า งานในแอปหลักไม่ถูกแตะ
- **service worker แยก**: scope `/clear/` · แคช `studentos-clear-*` · ตัวหลักไม่ดักคำขอใต้ `/clear/` และไม่ลบแคชกันเอง
- โค้ดลับ "ล้างทุกอย่าง" ถอนเฉพาะ service worker และแคชของ clear
- ชื่อแอป "Student OS Clear" (ติดตั้งแยกจากแอปหลักได้) · `noindex`
- **ยังใช้ร่วมกับแอปหลัก**: บัญชี Supabase · ข้อมูลบน cloud แถวเดียวกัน (`user_state`) · การล็อกอิน (ออกจากระบบที่ไหน ออกทั้งสองที่) · แคชรูปอีเวนต์
- ทดสอบในเบราว์เซอร์: clear เปิดเปล่า · งานแอปหลักยังอยู่ · SW สองตัวแยก scope · ไม่มี JS error · ยังไม่ได้ลองล็อกอินจริง/มือถือจริง
