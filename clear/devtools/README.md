# Clear · เครื่องมือ CSS (เฟส 4 · 16 พ.ย. 69)

ไฟล์ CSS ใน `clear/` (ยกเว้น `style.css` และ `clear.css`) ถูกเขียนใหม่ด้วยสองสคริปต์นี้ —
**คอมเมนต์ถูกตัดออกหมด** ถ้าต้องการอ่านเหตุผลของกฎไหน ดูไฟล์ชื่อเดียวกันที่รากของ repo (แอปหลัก)

ต้องมี `pip install tinycss2` · รันจากโฟลเดอร์ `clear/` · รันซ้ำได้ (ผลเท่าเดิม)

1. `python3 devtools/css-prune-themes.py <ไฟล์.css ...>`
   ตัดกฎของธีมที่ Clear ไม่มี (เหลือ light/dark) และ Halloween (`.hw-season` · `[data-hw-tone]`)
   ทิ้งเฉพาะส่วนของ selector list ที่อ้างธีมอื่นแบบบวก · อ้างใน `:not(...)` ไม่นับ
2. `python3 devtools/css-expand-is.py <ไฟล์.css ...>`
   `X :is(.a, .b)` ที่อยู่ขวาสุด → `X .a, X .b` เพื่อให้ Chrome คัดกฎทิ้งตามคลาสได้
   (`:is()` หลายตัวเลือกขวาสุด = ลองกับทุก element ทุกครั้งที่คิดสไตล์ · วัด 9 พ.ย. 69 = ~80% ของเวลาจับคู่)
   ความเจาะจงเท่าเดิมเป๊ะด้วย `:not(#z)` / `:not(.z)` / `:not(z)` · ตัวเลือกที่มีช่องว่าง/`>` ไม่แตก

ตรวจทุกครั้งหลังรัน: ถ่ายภาพหน้าจอก่อน/หลัง (ธีมสว่าง + มืด) ต้องตรงกันทุกพิกเซล
