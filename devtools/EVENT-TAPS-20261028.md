# แก้อาการต้องแตะซ้ำ · main · 28 ตุลาคม 2569

ผู้ใช้สั่งแก้ทั้งหมดและทยอยขึ้นเว็บหลักทีละข้อ คง 1C60, เพลง, คีย์เซฟและตัวตัดสินรางวัลฝั่งเซิร์ฟเวอร์ ไม่ล้างหรือแจกของจริง ไม่เปลี่ยน ALT

## 1. เกมพักสมอง
- เปิดสถานะโหลดทันที ไม่ต้องแตะซ้ำก่อน round จากบัญชีจะมาถึง ป้องกันเริ่มรอบซ้อน
- รับคำตอบครั้งเดียว แสดงว่ารอเซิร์ฟเวอร์ ปิดได้ทันทีและกลับมาเล่นรอบเดิม เกมพักสมองไม่จับเวลาและไม่แจก Candy
- นาฬิกาเผยรูนไม่ปลดปุ่มระหว่างรอ และคำตอบช้าไม่วาดหน้าต่างที่ปิดแล้ว
- ทดสอบ race/failure ใหม่ 3 กรณี เห็นตกก่อนแก้และผ่านหลังแก้ รวม main release/stability 22 ผ่าน
- ทดลอง UI กรอบ 375×812 คำขอช้า 3 วินาที เปิด/พัก/เปิดรอบเดิม/ขอคำใบ้แล้วพัก ได้ทันที ไม่มี JS error ที่จับได้ ไม่ใช่มือถือจริงหรือธุรกรรมบัญชีจริง

## 2. หน้าบอส
- แสดงโหลดและรอเทิร์น ปิดหน้าต่างได้ทันที ส่งการถอยตามหลังเทิร์นที่ค้างให้เซิร์ฟเวอร์ตัดสิน ไม่ส่งท่าซ้อน ไม่ยกเลิกผลที่บันทึกแล้ว
- คำตอบช้าไม่เปิดสนามหรือวาดทับหน้าต่างใหม่ รางวัลที่ได้จริงยังอยู่ในคลัง ความผิดพลาดเปิดให้ลองใหม่
- กันเริ่มสนามซ้ำระหว่างเตรียมทางเข้าและใช้ฉาก WebP แทน PNG รวมถึงสนามฝึก
- ทดสอบ race/failure เพิ่ม 3 กรณี เห็นตกก่อนแก้ รวมชุด main 25 ผ่าน; UI คำขอช้า 3 วินาทีแสดงปุ่มรอและถอยกลับหน้ารายละเอียดบอสได้ทันที
- ข้อ 1: Pages run 40650763100 success และไฟล์ brain-ui.js บนเว็บจริงมีสถานะโหลด/รอชุดใหม่แล้ว

## 3. จุดกดในแผนที่
- ย้ายจุดแลกของไปด้านตรงข้าม NPC ของแต่ละไบโอม ทั้งจอมือถือและคอม ไม่แปะทับตัว Tang/Dech อีก
- ตรวจ center hit-test ของปุ่มที่อยู่ใน viewport ทั้ง 4 ไบโอม × 320×740, 375×812, 430×932, 1100×720 รวม 16 แบบ ไม่พบปุ่มถูกบัง/ล้นแนวนอน/รูปเสีย/JS error ที่จับได้
- กดพิกัดกลางตัว Dech จากภาพจริงครั้งเดียวเปิดเควส Mr. Dech ไม่เปิดนักเดินทาง หลักฐานใน outputs/taps-dech-map-fixed.png และ taps-map-checks.json ไม่ส่งขึ้นเว็บ

## 4. ร้านค้าตอนคำตอบช้า
- ปิดร้านแล้วไม่เปิดเองเมื่อคำตอบซื้อ/ขายกลับมา ทั้งกรณีสำเร็จและล้มเหลว ผลที่บันทึกจริงยังอยู่และมีข้อความให้ตรวจคลัง ไม่เปิดฉากรับของทับหน้าที่ผู้เล่นย้ายไป
- ปลดสถานะรอได้แม้คำขอผิดพลาดและใช้ข้อความรอยืนยันตามจริง ไม่ยืนยันว่าไม่มีการบันทึกในกรณีเน็ตขาด
- มือถือใช้แตะหยิบและเลื่อนตามปกติ ไม่เข้าโหมดลากเพราะนิ้วขยับเล็กน้อย คอม/ปากกายังลากได้
- เพิ่มเคสคำตอบสำเร็จ/ล้มเหลวมาช้าหลังปิด 2 กรณี เห็นตกก่อนแก้ รวม main regression 27 ผ่าน
- UI ทดสอบคำขอช้า 3 วินาทีและล้มเหลวก่อนบันทึก ปิดร้านแล้วอยู่โถงตามเดิม Candy 1,000 ไม่เปลี่ยน ไม่มี JS error ที่จับได้

## 5. พื้นที่ปุ่มระหว่างแตะ
- เปลี่ยนการหดทั้งปุ่มตั้งแต่ pointerdown เป็นแสงตอบรับ พื้นที่กดอยู่ที่เดิมจนปล่อยนิ้ว และไม่บังคับอ่าน layout ทุกครั้งที่แตะ
- regression จับการเปลี่ยน geometry และ forced layout เห็นตกก่อนแก้ ผ่านหลังแก้ คงอนิเมชันตกแต่งอื่น
- ข้อ 2–4: Pages runs 40651053496, 40651316055, 40651703322 สำเร็จแล้ว

## งานที่ต้องต่อ
- แก้บทพูดจบ Dech Quest 3 ให้ตรงว่าธีมได้รับหลังชนะบอส ไม่เปลี่ยนกติกาหรือรางวัล
- ตรวจเหตุอาการแตะซ้ำที่อาจเหลือในตัวควบคุมหลัก: feedback.js ทำ scale ปุ่มตั้งแต่ pointerdown/บังคับ layout; experience.js มี silent navigation ที่รอโดยไม่บอกสถานะและการ refresh ทุก 30 วินาทีอาจ render ระหว่างนิ้วแตะ ต้องพิสูจน์ก่อนแก้
- ตรวจ error recovery ของปุ่มส่งเควส/บ้าน/เข้าประตู/สวนเมื่อเน็ตช้า ป้องกัน late response เปลี่ยนฉากและคำขอซ้อนโดยไม่ลดการตรวจเซิร์ฟเวอร์
- ตรวจชุด main regression ทั้งหมดและ worker หลังแพตช์สุดท้าย ตรวจ Pages success/ไฟล์ live จริง ไม่อ้างมือถือจริงหรือไม่มีบั๊กทุกเครื่อง
