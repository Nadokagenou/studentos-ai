# แก้อาการต้องแตะซ้ำ · main · 28 ตุลาคม 2569

ผู้ใช้สั่งแก้ทั้งหมดและทยอยขึ้นเว็บหลักทีละข้อ คง 1C60, เพลง, คีย์เซฟและตัวตัดสินรางวัลฝั่งเซิร์ฟเวอร์ ไม่ล้างหรือแจกของจริง ไม่เปลี่ยน ALT

## 1. เกมพักสมอง
- เปิดสถานะโหลดทันที ไม่ต้องแตะซ้ำก่อน round จากบัญชีจะมาถึง ป้องกันเริ่มรอบซ้อน
- รับคำตอบครั้งเดียว แสดงว่ารอเซิร์ฟเวอร์ ปิดได้ทันทีและกลับมาเล่นรอบเดิม เกมพักสมองไม่จับเวลาและไม่แจก Candy
- นาฬิกาเผยรูนไม่ปลดปุ่มระหว่างรอ และคำตอบช้าไม่วาดหน้าต่างที่ปิดแล้ว
- ทดสอบ race/failure ใหม่ 3 กรณี เห็นตกก่อนแก้และผ่านหลังแก้ รวม main release/stability 22 ผ่าน
- ทดลอง UI กรอบ 375×812 คำขอช้า 3 วินาที เปิด/พัก/เปิดรอบเดิม/ขอคำใบ้แล้วพัก ได้ทันที ไม่มี JS error ที่จับได้ ไม่ใช่มือถือจริงหรือธุรกรรมบัญชีจริง

## 2. หน้าบอส
- แสดงโหลดและรอเทิร์น ปิดหน้าต่างได้ทันที ส่งการถอยตามหลังเทิร์นที่ค้างให้เซิร์ฟเวอร์ตัดสิน ไม่ส่งท่าซ้อน ไม่ยกเลิกผลที่บันทึกแล้ว
- คำตอบช้าไม่เปิดสนามหรือวาดทับหน้าต่างใหม่ รางวัลที่ได้จริงยังอยู่ในคลัง ความผิดพลาดเปิดให้ลองใหม่
- กันเริ่มสนามซ้ำระหว่างเตรียมทางเข้าและใช้ฉาก WebP แทน PNG รวมถึงสนามฝึก
- ทดสอบ race/failure เพิ่ม 3 กรณี เห็นตกก่อนแก้ รวมชุด main 25 ผ่าน; UI คำขอช้า 3 วินาทีแสดงปุ่มรอและถอยกลับหน้ารายละเอียดบอสได้ทันที
- ข้อ 1: Pages run 40650763100 success และไฟล์ brain-ui.js บนเว็บจริงมีสถานะโหลด/รอชุดใหม่แล้ว
