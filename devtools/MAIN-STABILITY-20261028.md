# แพตช์เร่งด่วนเวอร์ชันหลัก · 28 ตุลาคม 2569

ผู้ใช้แจ้งว่ามือถือกดไม่ติด ต้องกดย้ำ ส่งเควสไม่ได้ทุกบัญชี และขอให้เลิกเชื่อมหน้าหลักกับ ALT จึงแยกไฟล์ส่วนหน้าเว็บมาเป็นของ main โดยคงบัญชีและบริการเดิม

- main ใช้ halloween/ และ economy/ ของตัวเอง รวมข่าวสารใน news/; ไม่มี script/link/ภาพ/ข้อมูลเกมที่ต้องโหลดจาก alt/
- ไม่เปิดใช้ sync-to-root.py และปิด --apply ของ main-ui-parity.py เพื่อไม่เขียน ALT กลับมาทับ main
- หน้าธีมแสดงเฉพาะสิทธิ์ที่ได้รับจริง รวมธีมอีเวนต์/ธีมลับ/Genesis; ไม่ใช้ธีมที่เคยเลือกเป็นหลักฐานว่ามีสิทธิ์
- เอาลิงก์ห้องชมฉาก Halloween ออกจากหน้าผู้ใช้ และไม่เผยแพร่ cinematic-preview.html ใน main
- การแตะ NPC/แผนที่ไม่ต้องแตะครั้งแรกเพื่อ arm; ไม่รอ AudioContext ก่อนทำคำสั่ง; เสียง/อนิเมชันล้มต้องไม่ทำให้รายการที่บันทึกสำเร็จถูกแจ้งว่าล้มเหลว
- ส่งเควสล้มเหลวคืนปุ่มที่เก็บอ้างอิงไว้ ไม่ใช้ event.currentTarget หลัง await ซึ่งเป็น null ได้
- ระหว่างเปลี่ยนฉากไม่ต่อคิวคำสั่งเดินทางซ้ำ และมีสถานะกำลังเปิด
- การอ่านคลังซ้ำ/โฟกัสที่ไม่เปลี่ยนของ ไม่สั่งสร้างทุกปุ่มของแอปใหม่ใต้ปลายนิ้ว; ข้อมูลโฟกัสยังอัปเดตใน cache ตามเดิม
- มือถือ/จอสัมผัสลด backdrop blur และหมอกที่ใช้ filter หนัก พักฉากหลังเมื่อเปิดหน้าต่าง อ่านเควสได้ลื่นขึ้น โดยไม่เปลี่ยนเพลงหรือกติกา
- คงเลข1C60 คีย์เซฟ config/manifest/ตัวเชื่อม Classroom/LINE และบริการ Supabase เดิม ไม่มีการล้างหรือแจกของจริง การล้างของเฉพาะบัญชีถูกพักตามแนวทางใหม่
