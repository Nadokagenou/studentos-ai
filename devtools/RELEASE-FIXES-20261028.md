# แก้ 7 จุดหลังเปิดอีเวนต์ · 28 ตุลาคม 2569

ผู้ใช้สั่งแก้ทั้งหมดและทยอยเผยแพร่ทันทีที่แต่ละชุดพร้อม คง 1C60 แก้เฉพาะ main frontend ไม่เปลี่ยนคีย์เซฟ บัญชี เพลง หรือกติการางวัลที่เซิร์ฟเวอร์ตัดสิน ไม่มีการล้างหรือแจกของจริง

1. มินิเกมแสดงสถานะรอและปิดหน้าต่างได้ ผลตอบช้าไม่เปิดหน้าต่างกลับมา รอบเดิมใช้ session/deadline เดิม เปิดกลับแสดงว่าเล่นต่อ จำกัดเวลารอคำขอ 12 วินาทีต่อครั้ง และ retry ด้วยเลขรายการเดิมเพื่อกันบันทึกซ้ำ
2. ระหว่าง refresh บัญชีเดิมคงสิทธิ์ที่เคยยืนยันไว้ สลับบัญชีหรืออ่านไม่สำเร็จยังปิดสิทธิ์ ไม่ใช้ค่าของทดลองปลดล็อก
3. Tang กับ Spectral Lantern เดิม ตรวจตรงกันทั้งภารกิจและหน้าส่ง ไม่เรียกหรือหักของคราฟต์ซ้ำ ใช้ข้อยกเว้นเดิมของ engine
4. ภาพ 15 ไฟล์เป็น WebP lossless ขนาดรวม 41,738,143 → 32,256,800 bytes ตรวจ RGBA และขนาดตรงต้นฉบับทุกไฟล์ มือถือไม่โหลดภาพแนวนอนซ้ำเพื่อทำพื้น blur เต็มจอ เก็บ PNG เดิมให้แท็บรุ่นเก่ายังอ่านได้ ภาพเกมไม่กลับเข้า initial precache
5. เปิดประตูส่ง enter-hub ครั้งเดียว นำผลที่ยืนยันแล้วไปเปลี่ยนฉาก ไม่รอธุรกรรมซ้ำ
6. หน้า rewards.html เป็นคอลเลกชันผู้เล่น 30 ชิ้น ลบห้องทีม/ลิงก์ตรวจจอ/เครื่องมือลองจากหน้านั้น หน้าลิงก์เก่าพาเข้าคอลเลกชันที่มีอยู่จริง
7. แยก loading/error/ไม่มีอีเวนต์ที่ยืนยันแล้ว มีปุ่มลองใหม่และ timeout ของข้อมูลกิจกรรม ยอด Candy มาจากตัวอ่านสิทธิ์บัญชีเดียวกัน ไม่ต้องรอเข้าโฟกัสก่อน มีสถานะตรวจยอด/เข้าสู่ระบบ/ลองอ่านใหม่

- main-release.test.mjs 9 กรณีใหม่ ผ่าน และแสดงความล้มเหลวของพฤติกรรมเดิมก่อนแก้
- ชุด UI/กติกา/บัญชีรวม 329/329; root account switch 33/33; main worker 6/6 รวม 368 ผ่าน
- ข้อมูลจำลองครบเงื่อนไข 18 เฟสเควสผ่าน รวม Dech Q3; เคสตะเกียงเดิม engine กับ UI พร้อมตรงกัน
- หน้าเกมในกรอบ 375×812 กดส่ง Tang ครั้งเดียวสำเร็จ เปิดและปิด Ghost Ship Hunt ได้ ภาพไม่แตกและไม่ล้นแนวนอน หน้าคอลเลกชันเปิดรายละเอียด Cruor Quill ได้ ไม่มีห้องทีม
- เว็บจริง main precache 252 ไฟล์และภาพ WebP 29 ไฟล์ตอบ 200; ตรวจ source markers ครบ 7 จุด; protected hashes 113 ไฟล์ตรงเดิม
- แต่ละชุด push main ตามคำสั่ง ชุดสุดท้ายต้องยืนยัน Pages success และ source จริงก่อนรายงานเสร็จ

## ขอบเขต

การปิดเกมปิดหน้าต่างได้ทันที แต่ไม่หยุดเวลาเซิร์ฟเวอร์หรือทำให้ได้รางวัลฟรี ไม่อ้างว่าชดเชยความหน่วงอินเทอร์เน็ตทุกระดับ หรือลองโทรศัพท์จริงครบทุกเครื่อง ยังไม่ได้ทดสอบโฟกัสจริง 20 นาทีหรือสองเครื่องพร้อมกัน รอบนี้ไม่มี backend/schema migration และไม่มีการเปลี่ยนระบบ Classroom/LINE
