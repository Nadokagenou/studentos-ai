งานก่อนหน้าใน `alt/` และ StudentOS Fresh Start เป็นคนละงาน ไม่ได้นำมาปล่อยในสาขานี้
คำสั่งของเจ้าของครั้งนี้อนุญาตให้แก้ root ตามข้อยกเว้นใน AGENTS.md ที่ห้ามแตะ root ถ้าไม่ได้สั่ง

## การปรับ

- เพิ่ม `desktop.css` ผังจอกว้างตั้งแต่1024px ใช้กรอบแอป100%×100dvh ไม่มีกรอบมือถือและนาฬิกาจำลอง
- ใช้ปุ่มนำทางเดิมทั้ง5ปุ่มในแถบซ้ายกว้าง216px (184px ที่1024–1199px) ป้ายและแบดจ์เดิมยังอยู่
- หน้าวันนี้: งานที่ระบบเลือกด้านซ้าย น้องฮูกและคิวที่เหลือด้านขวา ช่องถามและทางลัดเดิม8ปุ่มเป็นแถวกะทัดรัด
- หน้าอื่นขยายพื้นที่เนื้อหาและฟอร์ม แผ่นเพิ่มงานกว้าง600px โฟกัสคลุมจอ กล่องแจ้งผลยังเป็นแคปซูลสูงตามข้อความ
- สีอ่านจากโทเคนธีมเดิม ไม่มีการบังคับเปลี่ยนธีม ไม่มี JavaScript หรือไลบรารีกราฟิกเพิ่มในแอปจริง
- `index.html` เพิ่มlink CSSที่มีmedia1024px `sw.js` แคชCSSใหม่และเปลี่ยนท้ายชื่อแคช ไม่เปลี่ยนเลขรุ่น1C60หรือนโยบายpush
- ไม่แก้ `style.css`, `app.js`, engine/planner, config หรือคีย์ข้อมูล ไม่มีไฟล์ใต้`alt/`ที่เปลี่ยนในสาขานี้

## ตรวจแล้ว

ข้อมูลจำลองในเครื่อง วันที่20ตุลาคม2569 ตั้งแต่19:00 และ22:30 มีป้ายระบุในภาพ ไม่มีบัญชี cloud และใช้SWจำลองเฉพาะพรีวิว

- จอ1280×720: แอป1280×720 เมนู216px เนื้อห1064px ปุ่มเริ่มและทางลัด8ปุ่มอยู่ในจอในกรณีตัวอย่างปกติ
- จอ1024×768: แอปเต็มจอ เมนู184px หน้าวันนี้scrollHeightเท่ากับclientHeight768 ปุ่มเริ่มและทางลัดอยู่ในจอ ไม่มีแนวนอนล้น
- จอ1440×900: แอปเต็มจอ หน้าวันนี้scrollHeightเท่ากับclientHeight900 ไม่มีแนวนอนล้น
- ย่อ1440→960: ผังเดิมกลับมา ไม่มีแนวนอนล้น
- มือถือ375×812: ถอดdesktop.cssเพื่อเปรียบเทียบแล้วตำแหน่งปุ่ม/ขนาดเนื้อหาเท่ากัน (home1032px, screen803/scroll1108px) ยืนยันว่าไม่เกิดความยาวเพิ่มจากงานนี้
- หน้าแรกมือถือเดิมเลื่อนได้อยู่แล้วในข้อมูลตัวอย่างนี้ ไม่อ้างว่ากฎ375×812ไม่เลื่อนผ่านหรือทดสอบFPSเครื่องจริงแล้ว
- เปิดหน้า งานวันนี้/รายการ, แผนวันนี้, ตารางเต็มวัน, ผู้ช่วย, โปรไฟล์, ตั้งค่า และฟอร์มเพิ่มงานได้
- บันทึกงานตัวอย่างได้ เริ่มโฟกัสและทำเสร็จได้ จอสรุปบอกชีววิทยาเป็นงานถัดไป กลับหน้าแรกแล้วจำนวนงานลดถูกต้อง
- แผ่นเพิ่มงานอยู่กลางจอ โฟกัสเต็ม1280×720 ปุ่มปิด/เสร็จไม่ถูกเมนูบัง
- กล่องแจ้งบันทึกมีขนาด480×64 อยู่y16 ไม่ยืดลงทั้งจอ
- ตรวจภาพธีมlight/dark/galaxy/magic และสถานะงานว่าง/หมดเวลาว่าง ไม่มีการ์ดซ้อนทับกัน
- login, cloud AI, การส่งข้อความ, การแจ้งเตือนจากระบบ และโหมดออฟไลน์ในเบราว์เซอร์จริงไม่ได้ทดสอบในรอบนี้
