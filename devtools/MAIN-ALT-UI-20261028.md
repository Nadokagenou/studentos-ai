# เวอร์ชันหลักหน้าตาเหมือน ALT · 28 ตุลาคม 2569

ผู้ใช้ระบุให้ /studentos-ai/ มีหน้าตาทุกอย่างเหมือน ALT จึงอัปเดตส่วนหน้าเว็บที่รากตามคำสั่งรอบนี้ โดยไม่เปิดสคริปต์ sync-to-root.py ที่ถูกพักไว้

## ผลลัพธ์
- หน้าโหลดและหน้าล็อกอินตามฉาก Halloween ของ ALT
- หน้าแรกแบบใหม่ แบนเนอร์สลับงาน/อีเวนต์ หน้างาน หน้าตั้งค่า และหน้าจอคอมตาม ALT
- ธีม Halloween, Moon & Candle, เรือนลับแล และธีมไบโอม รวมหมวดความหายาก เพลงเดิมของธีมถูกนำมาใช้ผ่านไฟล์ร่วมเดิม
- ตราหลักและตราอีเวนต์ การเลือกตราโปรไฟล์ คลังและฉากงานเสร็จตามสิทธิ์บัญชีจริง
- ใช้ภาพ แคตตาล็อก และโมดูลรางวัลชุดเดียวใน alt/halloween/ ไม่สร้างคลังบัญชีหรือฐานข้อมูลชุดใหม่
- หน้า main ส่ง entry=main ไปหน้าเกม/พันธสัญญา และทางกลับห้องชมฉาก/คลังกลับหน้าหลักได้
- แก้รูปโลโก้/ชุดไซของ theme-main.js ให้ resolve จากไฟล์สคริปต์จริง เพื่อโหลดได้ทั้ง root และ ALT
- หน้าแรก 375×812 ปุ่มรองยังมีพื้นที่แตะอย่างน้อย44px และเห็นครบเหนือแท็บล่าง ปรับช่องว่างและปุ่มรองร่วมกันทั้งสองรุ่น

## รักษาของเดิม
- ไม่เปลี่ยน config.js, manifest.json, integrations.js, linelink.js, brain.js, inbox.js, engine.js, context.js, planner.js หรือ style.css ของ root
- ไม่เปลี่ยนไฟล์ Supabase functions/migrations/config หรือเผยแพร่บริการบัญชีใหม่
- ตรวจ hash ของไฟล์ที่คงไว้113ไฟล์ตรงก่อนแก้ รวม config/ตัวเชื่อมและไฟล์เซิร์ฟเวอร์
- คง STORE_KEY/OWNER_KEY และคีย์เซฟเดิม ไม่มีคำสั่งล้างหรือย้ายข้อมูลบัญชี/การเชื่อม
- main ยังเป็นเจ้าของการแจ้งเตือนระบบ (ALT_SYSTEM_NOTIFICATIONS=true) และใช้ manifest/scope/main cache เดิมของตนเอง
- คงเลขแอป1C60; cache main studentos-main-1c60-alt-ui-20261028, ALT studentos-alt-1c60-main-ui-20261028

## วิธีบำรุง
devtools/main-ui-parity.py เป็นรายการเฉพาะส่วนหน้าเว็บที่ได้รับอนุญาตรอบนี้ ปกติรันดูอย่างเดียว การเขียนต้องใส่ --apply และยังป้องกันไฟล์ที่ root เป็นเจ้าของ
