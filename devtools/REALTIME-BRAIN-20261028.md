# ตรวจเกมอื่นและความช้าต่อ · 28 ตุลาคม 2569

ผู้ใช้ขอให้ดูมินิเกมอื่นและความช้าด้วย พบเกมพักสมองทั้ง 6 แบบยังรอ brain-move ทุกคำตอบ/ทุกช่องที่เดิน จึงขยายการเล่นทันทีและตรวจลำดับตอนจบจากเกมเควสมาถึงเกมพักสมอง

- เซิร์ฟเวอร์เตรียมคำถามของรอบนั้นไว้ล่วงหน้า UI อ่านเฉพาะสำเนารอบเล่นและกติกาเดิม ไม่ต้องเข้าถึง seed ส่วนตัวของเซิร์ฟเวอร์ เมื่อจบ/พัก/สะสมครบ 48 การกดส่ง brain-inputs ไปตรวจทีละคำตอบแบบ atomic การดูรูนยังรอ 4500ms ตามเดิม ไม่มี Candy หรือรางวัลจากเกมพักสมอง
- รองรับ math/balance/pattern/odd/path/memory และ brain-ready สำหรับรอบเก่าโดยรักษาคำถาม/ประวัติ/ความคืบหน้าที่เล่นอยู่ หน้าเก่ายังใช้ brain-move เดิมได้
- เมื่อการส่งผลล้มเหลวเก็บชุดเดิมให้ส่งอีกครั้งหรืออ่านเซฟล่าสุด ปิดหน้าต่างแล้วไม่วาดผลตอบกลับทับหน้าอื่น เมื่ออ่านเซฟที่เป็นคนละรอบ controller เปลี่ยน session ตามเซฟนั้นด้วย
- เซิร์ฟเวอร์ตรวจ session, จำนวน/รูปแบบ inputs, ลำดับและขอบเขตเวลา, เป้าหมาย และเวลาเผยรูน ไม่รับคำสั่งแจกรางวัลจาก client คง Auth/JWT/receipt/CAS/rate limit เดิม

หลักฐาน: 386 เคสผ่าน รวมเล่นครบทั้ง 6 แบบด้วย public document ที่ไม่มี private rng; ส่งลำดับผิด/ก่อนเผยรูน/อนาคต/ผิด session ถูกปฏิเสธ; upgrade ไม่ล้างคำถาม; ปิดแล้ว retry ใช้ชุดเดิม; อ่านเซฟใหม่เปลี่ยน session; UI ตอบเลขทั้ง 3 ด่านก่อน deferred save ตอบและค่อยแจ้งสำเร็จหลังยืนยัน Main SW 6/6 ผ่าน บริการ halloween-event v9 ACTIVE/JWT ดาวน์โหลดกลับตรงไฟล์ที่ส่งทั้ง3ไฟล์

ตรวจ log production แบบรวมช่วง 2026-10-28 13:00–14:12 UTC เฉพาะ POST halloween-event: Sydney 170 คำขอสำเร็จ เฉลี่ย664ms/p95ประมาณ1131ms/สูงสุด2553ms; Singapore 64 คำขอสำเร็จ เฉลี่ย1411ms/p95ประมาณ3421ms/สูงสุด4143ms ตัวอย่างผสมทั้งอ่าน/เขียนและอาจต่างผู้ใช้ จึงไม่ใช่การเทียบคำขอชนิดเดียวกันหรือรับรองความเร็วทุกเครื่อง ไม่พบ HTTP error ในตัวอย่างช่วงนี้ แต่ยังมีคำขอตอบช้าจึงไม่อ้างว่าหายทั้งหมด

ตั้ง heartbeat แบบอ่านอย่างเดียวทุก6ชั่วโมงสำหรับมินิเกม/ไฟล์ที่เผยแพร่/สรุปความช้า แจ้งเฉพาะปัญหาหรือความเปลี่ยนแปลงที่ต้องดำเนินการ ไม่สร้างบัญชี QA หรือ deploy อัตโนมัติในรอบติดตาม

บอส/สนามฝึกยังเป็นเทิร์นที่ยืนยันผ่านเซิร์ฟเวอร์ ตรวจ regression การกดซ้ำ/ปิดขณะรอ/เครือข่ายล้มเหลวผ่าน ยังไม่ได้เปลี่ยนการตัดสินผลบอสให้เป็น local playback ในชุดนี้

ตรวจหน้า main จริงด้วยเซฟจำลอง QA 375×812 และเน็ตหน่วง3วินาที: จำรูนครบ3ด่านได้โดยไม่รอรายกด จำลองส่งผลล้มเหลวก่อนcommit แล้วกดส่งชุดเดิมสำเร็จ พบรหัสข้อความ error เก่าค้างหลัง retry จึงแก้การล้างข้อความและเพิ่ม assertion ครอบคลุม คำนวณยาอีก3ด่านตอบต่อเนื่อง1→2→3 ก่อน saveตอบ แล้วแสดงผลยืนยันสำเร็จ ไม่พบ JS errors/overflow/ภาพเสียในรอบนี้ ไม่ใช่การทดสอบมือถือหรือบัญชีผู้เล่นจริง ไม่มีการสร้างบัญชี QA production เพิ่มในชุดนี้
