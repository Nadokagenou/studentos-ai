# มินิเกมเควสตอบสนองทันที · 28 ตุลาคม 2569

สาเหตุเดิม: ทุก game-move รอ Auth/ฐานข้อมูลก่อนวาดเป้าหมายถัดไป จึงทำให้เกมจับเวลาและเกมกดต่อเนื่องสะดุดตามความหน่วงเครือข่าย

- main เล่นรอบที่เซิร์ฟเวอร์สร้างบนสำเนาหน้าจอทันที สำหรับเรือ ถางสวน จับผิดภาพ จับคู่สุสาน และจับผี รวม 5 เกม ส่งลำดับการกดตอนจบรอบหรือปิดหน้าต่าง รอบยาวเก็บช่วงละ 48 การกด
- เซิร์ฟเวอร์แจกสัญญาณเรือให้รอบนั้น ตรวจ session/เป้าหมาย/ลำดับเวลา/เวลาเผยรูน/เวลาคว่ำการ์ด แล้วใช้กติกาเกมเดิมคำนวณผลทีละการกด จึงไม่มีคำสั่งส่งว่าเล่นชนะหรือให้รางวัลเอง
- ผลที่หน้าจอเล่นครบแสดงกำลังตรวจและบันทึก จนได้รับเซฟที่ยืนยันแล้วจึงแสดงว่าสำเร็จและรับรางวัล Retry เก็บชุดการกดเดิม และ account-store ยังใช้ receipt เดิมเมื่อคำตอบสูญหาย ปิดหน้าต่างแล้วไม่วาดผลตอบกลับทับฉากอื่น
- รับเวลาที่คำขอถึงบริการก่อนรอ Auth/ฐานข้อมูล เซิร์ฟเวอร์ไม่ยอมรับเวลาการกดในอนาคต ย้อนลำดับ หรือผลชนะเกมจับเวลาที่มาถึงหลังเส้นตาย ปฏิเสธทั้งชุดโดยไม่บันทึกบางส่วน
- หน้าเก่ายังส่ง game-move เดิมได้ รอบที่ยังไม่จบอัปเกรดผ่าน game-ready โดยไม่ล้างคะแนนหรือขยายเส้นตาย ไม่เปลี่ยนจำนวนรางวัล ราคา กติกา 1C60 คีย์เซฟ หรือเพลง

การตรวจที่ทำจริง:

1. ชุดรวม 375 เคสผ่าน รวม 8 เคส replay/ตรวจเวลาบน authority และ UI เรือที่กดครบ 6 ครั้งก่อน deferred save ตอบ ไม่มีการแก้เซฟจริงจาก client ก่อนยืนยัน
2. main SW 6/6 และ main account isolation 33/33 ผ่าน
3. หน้า main จริงในเซฟ QA จำลอง 375×812 เปิดเรือและตั้งเครือข่ายหน่วง 3 วินาที กดตามสัญญาณทั้ง 6 ครั้งต่อเนื่องได้ ผลเพิ่ม 1→6 ทันที ไม่มีผิด/หมดเวลา ส่ง game-inputs เพียงครั้งเดียวตอนจบ หลัง 3 วินาทียืนยัน Candy +35 และ Soul Anchor +1 ไม่พบ JS error/ภาพเสีย/overflow ในรอบนี้ เกมจับคู่แสดงไพ่ทันทีและล็อกเฉพาะ 700ms ตอนเปิดไม่ตรงคู่
4. halloween-event v8 ACTIVE พร้อม JWT ดาวน์โหลดกลับตรงกับไฟล์ที่ส่งทั้ง 3 ไฟล์
5. บัญชี QA ชั่วคราวที่ผู้ใช้อนุญาต ผ่าน production Auth → ชุดเริ่มต้น → Tang → เปิดเรือ → ส่ง 6 สัญญาณจากรอบเซิร์ฟเวอร์ในชุดเดียว สำเร็จ revision6/Candy35/Anchor1 ส่ง receipt เดิมซ้ำ replay=true/revision6/รางวัลเท่าเดิม ตรวจ DB ยืนยัน 6 receipts ก่อนลบ บัญชี/identity/session/event state/receipts/profile/user state/economy/baseline เหลือ 0 และลบไฟล์ credentials แล้ว นี่คือ API smoke test ไม่ใช่การเล่นทดแทนผู้เล่นจริง

ยังมีเวลาเครือข่ายตอนเปิดรอบและยืนยันผล การตัดการเชื่อมต่อไม่ได้ยืนยันรางวัลออฟไลน์ การต่อสู้บอสและเกมพักสมองยังใช้เส้นทางผลตอบกลับเดิม ไม่ได้อ้างว่าแก้เป็น realtime ในชุดนี้
