# เว็บหลัก: นับถอยหลัง Halloween · 26 ตุลาคม 2569

เจ้าของระบุชัดในแชตว่าเป็น /studentos-ai/ ที่ไม่มี /alt/ จึงแก้ไฟล์ root ตามข้อยกเว้นที่ได้รับอนุญาต ไม่ย้ายงานของอีกทีมจาก ALT มาทับเว็บหลัก

- การ์ดใต้หัวทักทาย นับวัน/ชั่วโมง/นาที/วินาทีจริงจาก startsAt/endsAt ใน alt/halloween/event/config.json (fetch no-store) จุดเริ่ม 28 ต.ค. 2569 00:00 +07:00 จุดจบ 1 ธ.ค. 00:00 +07:00 จึงรวมทั้งวันที่ 30 พ.ย.
- ก่อนเปิด กดดูรายละเอียด/ภาพสี่ไบโอม ไม่มีลิงก์เข้า preview และยังไม่ให้ปุ่มเข้าเล่น พอเปิดเปลี่ยนเป็นลิงก์ alt/halloween/event/?entry=main เมื่อจบหรือ disabled การ์ดหายเอง ถ้าพักรับผู้เล่นแสดงรอประกาศ
- เป็น UI ประกาศเท่านั้น ไม่ใช้เวลาฝั่งนี้ตัดสินสิทธิ์ รางวัลยังอยู่ที่บริการบัญชีเดิม
- entry=main แก้เฉพาะหัวเว็บอีเวนต์ให้กลับ ../../../ ซึ่งคือเว็บหลัก ไม่รับ URL กลับจากภายนอก
- นาฬิกาเดียว อัปเดต text เท่านั้น หยุดเมื่อหน้าหลัก/รายละเอียดไม่แสดงหรืออยู่เบื้องหลัง กลับมาอ่าน deadline ใหม่ ไม่หักวินาทีสะสม อ่านสวิตช์อีเวนต์ใหม่ได้อย่างมากหนึ่งครั้งต่อนาที
- มือถือที่มีงานและการ์ดอีเวนต์ซ่อนแถวตัวเลขที่ซ้ำกับหัวจอและปุ่มทางเข้าน้องฮูกที่ซ้ำกับแท็บล่าง ปรับช่องไฟเฉพาะช่วงนี้ เพื่อให้หน้าแรกที่ 375×812 ไม่ต้องเลื่อน ทั้งกรณีไม่มีงานและมีงานทดสอบจริงหนึ่งใบ
- คงเลข1C60 และคีย์ทั้งหมด แยก halloween-countdown.js/css ไม่แตะ style.css เพิ่มสองไฟล์เข้า main SW ใช้แคช studentos-main-1c60-halloween-countdown-20261026 คงการแยกแคช ALT
