ข้อเท็จจริงที่พลิกสมมติฐานเดิม

ตัวเลขที่ต้องจ้องคือช่องขวาสุด — เราจ่ายตามขนาดกลุ่ม แต่ได้ประโยชน์ตามอัตราการเชื่อมบัญชี สองอย่างนี้ไม่ได้โตพร้อมกัน วันแรกที่บอทเข้าห้อง เราจ่ายค่าคน 40 คนทันทีทั้งที่อาจมีคนเชื่อมแค่ 3 คน

รูปทรงของต้นทุนอ่านได้สองอย่าง: ช่วงเล็กเจ็บเพราะค่าแพ็กเกจขั้นต่ำ (1 ห้องจ่ายเท่ากับ 10 ห้อง) ส่วนช่วงใหญ่ต้นทุนต่อคนนิ่งอยู่ที่ราว 1.9 บาท/คน/เดือน ซึ่งคือ 0.06 × 30 นั่นเอง — ไม่มีการประหยัดต่อขนาด ยิ่งโต ยิ่งจ่ายเป็นเส้นตรง

ตรงไหนฟรี ตรงไหนเสียเงิน

LINE ไม่ได้คิดเงินทุกอย่าง — และเส้นแบ่งอยู่ตรงที่ออกแบบรอบได้

วิธีส่งคิดเงินใช้ทำอะไรได้
Reply APIฟรี ไม่จำกัดตอบกลับข้อความที่เพิ่งเข้ามา ภายในอายุของ reply token
Auto-reply / Greetingฟรีข้อความต้อนรับตอนบอทเข้ากลุ่ม
Push / Multicastนับต่อผู้รับส่งเองตามเวลาที่เรากำหนด — สรุปประจำวันอยู่กลุ่มนี้
Broadcast / Narrowcastนับต่อผู้รับส่งหาทุกคนที่เป็นเพื่อนกับ OA
Web Push (ของเราเอง)ฟรีตลอดเตือนรายคนผ่านเบราว์เซอร์ — send-reminders ทำไว้แล้ว

ของเดิมยังไม่เสียเงินสักบาท — line-webhook/index.ts ตอนนี้เรียกแค่ /message/reply จุดเดียว ทั้งไฟล์ไม่มี push/multicast เลย ต้นทุน LINE ปัจจุบัน = 0

ข้อสรุปเชิงสถาปัตยกรรม

ถ้าต้นทุนต่อผู้ใช้จริงต้องเข้าใกล้ศูนย์ (ซึ่งต้องเป็น เพราะรายได้ยังเป็นศูนย์) เส้นแบ่งหน้าที่ต้องเป็นแบบนี้:

LINE = ชั้นรับงานเข้า · ห้ามเป็นชั้นแจ้งเตือน

ครูโพสต์การบ้านในกลุ่ม → บอท reply ต่อข้อความนั้นทันที (“บันทึกแล้ว: ใบงานเคมี · ส่งพฤหัส”) — ฟรี ไม่จำกัด และดีกว่าเดิมด้วย เพราะมันมาถูกจังหวะ ตอนที่ทุกคนยังมองจอกลุ่มอยู่

Web Push = ชั้นแจ้งเตือนรายคน — “เย็นนี้ควรทำอะไร” ส่งผ่าน send-reminders ที่มีอยู่แล้ว ฟรีทุกจำนวนผู้ใช้

พอแบ่งแบบนี้ สรุปประจำวันตอน 19:00 ทาง LINE ก็แทบไม่จำเป็น เพราะหน้าที่ของมันถูกแบ่งไปหมดแล้ว — การยืนยันว่าเก็บงานแล้วเกิดขึ้นทันทีที่ครูสั่ง ส่วนการตัดสินใจว่าคืนนี้ทำอะไรก่อนเป็นเรื่องของแต่ละคน ไม่ใช่เรื่องที่ต้องประกาศกลางกลุ่ม

ถ้ายังอยากได้ข้อความในกลุ่มจริง ๆ

  • ให้นักเรียนเรียกเอง — พิมพ์ “งาน” ในกลุ่ม บอทตอบด้วย reply = ฟรี และได้สัญญาณว่าใครสนใจจริงเป็นของแถม
  • ส่งเมื่อมีเหตุ ไม่ใช่ส่งตามเวลา — push เฉพาะตอนมีงานใหม่ที่ใกล้กำหนดจริง อาจเหลือสัปดาห์ละ 1–2 ครั้ง ลดต้นทุนลง 4–7 เท่าทันที
  • อย่าส่งเข้ากลุ่มที่คนเชื่อมบัญชีน้อย — ตั้งเกณฑ์ เช่น ต้องมีคนเชื่อม ≥ 30% ของห้องก่อนถึงจะเปิด push ให้ห้องนั้น

ก่อนเชื่อตัวเลขในหน้านี้

สามอย่างที่ต้องยืนยันด้วยตาตัวเองก่อนตัดสินใจผูกพัน

  • ราคาแพ็กเกจ — แหล่งที่ค้นเจอไม่ตรงกัน บางที่ว่า Free 200 บางที่ว่า 300 บางที่เรียกชื่อแพ็กเกจต่างกัน (Light/Standard vs Basic/Pro) หน้านี้ใช้ Free 300 · Basic 1,280฿/15,000 · Pro 1,780฿/35,000 · ส่วนเกิน 0.10 และ 0.06 บาท ให้เปิดหน้าราคาทางการยืนยัน
  • การนับในกลุ่ม — ยืนยันด้วยการทดลองจริง: สร้างกลุ่มทดสอบใส่คน 3 คน ยิง push 1 ครั้ง แล้วดูตัวเลขที่ LINE OA Manager ว่าขึ้น 1 หรือ 3
  • ค่าอื่นที่ยังไม่ได้รวม — หน้านี้คิดเฉพาะค่าข้อความ LINE ยังไม่รวม Supabase, ค่า OCR/AI ต่อครั้ง ซึ่งจะกลายเป็นก้อนใหญ่ถ้าเปิด cloud OCR เป็นค่าเริ่มต้น (อีกเหตุผลที่มันไม่ควรเป็นค่าเริ่มต้น)
