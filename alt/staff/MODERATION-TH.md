# แบนบัญชีและหักโทเคน — 16 ต.ค. 2569

ใน Control Room เปิดผู้ใช้งาน ค้นหาและกดจัดการบัญชี แล้วเลือกเพิ่ม/หักโทเคน หรือแบน 1 วัน / 2 วัน / ถาวร / ปลดแบน กรอกเหตุผลและตรวจชื่อกับรหัสบัญชีในหน้าต่างยืนยัน ทุกการเปลี่ยนแปลงเก็บในประวัติการจัดการ ผู้ใช้ได้รับข้อความส่วนตัวและเข้าคิว Push ตามสิทธิ์กับเวลางดรบกวนเดิม

## ขอบเขต

- Auth banned_until บล็อกการเข้าสู่ระบบและต่ออายุเซสชัน ข้อมูล Data API ตรวจตารางแบนทุกคำขอ จึงบล็อก JWT เดิมได้ก่อนหมดอายุด้วย
- restrictive RLS เพิ่มเงื่อนไขบัญชีที่ถูกแบนให้ตาราง public ที่เปิด RLS อยู่แล้วและ storage.objects รวม 37 ตาราง ไม่แทนที่นโยบายเดิม ไม่เพิ่มสิทธิ์อ่านตาราง
- ด่าน Data API เป็น SECURITY INVOKER ผู้ยังไม่ล็อกอินผ่านแบบไม่อ่านข้อมูลบัญชี บัญชีที่ล็อกอินอ่านสถานะ/ข้อความส่วนตัวของตนได้ระหว่าง JWT ยังมีอายุ
- งานและไฟล์ในเครื่องไม่ถูกลบ เว็บสาธารณะและไฟล์ที่เผยแพร่สาธารณะยังเปิดแบบไม่ล็อกอินได้ การแบนบัญชีไม่ได้ห้ามใช้เว็บออฟไลน์หรือป้องกันสร้างบัญชีใหม่
- Edge Functions เดิมที่ตรวจเฉพาะลายเซ็น JWT โดยไม่เรียก Auth/Data API อาจยังยอมรับ JWT ที่ออกก่อนแบนจนหมดอายุ ระบบนี้ไม่ได้เปลี่ยนโค้ด Edge Functions อื่นทั้งหมด
- ห้ามแบนหรือปลดแบนบัญชีแอดมินที่เป็นผู้สั่งรายการเอง ห้ามแทนที่การแบน Auth ภายนอกที่ไม่มีรายการใน Control Room
- แบนชั่วคราวสิ้นสุดด้วยเวลาเซิร์ฟเวอร์ ไม่ต้องพึ่งมือถือเปิดแอปหรือ cron; ถาวรปลดได้โดยผู้ดูแล

## โทเคน

หัก 1–10,000 ต่อรายการ ต้องมีบัญชีที่เคยซิงก์และยอดบนคลาวด์เพียงพอ ล็อกแถวผู้รับก่อนตรวจยอด บันทึก debit/audit/notice ในธุรกรรมเดียว มี request ID กันซ้ำ ใช้ตัวนับ staffDebited แยกจาก staffMinted เพื่อรับส่วนต่างครั้งเดียวทั้งสองหน้าแอป รักษางานและของสะสมเดิม

กระเป๋าเดิมยังซิงก์จากเครื่องผู้ใช้ การเพิ่ม/ใช้จ่ายทั่วไปยังไม่ใช่ server wallet ที่กันโกงครบวงจร บัญชีที่เจ้าของกำหนดให้แสดงยอดไม่จำกัดยังแสดง ∞ แม้ยอดจริงบนคลาวด์ถูกหักหนึ่งโทเคน ไม่เปลี่ยนสิทธิ์นั้นโดยอัตโนมัติ

## การตรวจ

ชุดทดสอบ moderation เพิ่ม 15 ข้อ: ยอดไม่พอ รายการซ้ำ snapshot เก่า การหมดอายุ สิทธิ์ผู้ใช้ RLS และ public request hook รวมกับชุด auth/security/report speed/news bridge/push queue ที่ผ่านแล้วเป็น 68 ข้อ ตรวจเว็บจริง public notices ตอบ 200 และ staff-console สำหรับผู้ไม่มีสิทธิ์ตอบ 401

Advisors: ตาราง staff ใหม่ตั้งใจเปิด RLS โดยไม่มีนโยบายและถอนสิทธิ์ client เพื่อปิด direct access; helper SECURITY DEFINER ที่เรียกได้โดย authenticated คืนเฉพาะสถานะบัญชีตนและกำหนด search_path ว่าง คำสั่งแอดมินยังเฉพาะ service_role

ทดสอบ Push จริงหนึ่งรายการไม่ได้แปลว่าพิสูจน์มือถือรับแล้ว ต้องแยกสถานะ provider ตอบรับจากการยืนยันบนมือถือ ห้ามยิงซ้ำเพื่อหาคำตอบโดยไม่จำเป็น
