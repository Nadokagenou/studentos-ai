# StudentOS Halloween · ห้องดูงานสำหรับทีม

> อัปเดตล่าสุด 22 ตุลาคม 2026: ของตกแต่ง 23 แบบเลือกใช้จริงใน ALT ได้แล้ว วัตถุ Mystical 4 ชิ้นกับเหรียญ 1 ชิ้นรอระบบอีเวนต์ ไม่เพิ่มลงคลัง ไม่ให้สิทธิ์ไอเทม และปุ่มลองชิ้นเหล่านั้นในคอลเลกชันยังปิดอยู่

เปิดดูและลองรางวัล: https://nadokagenou.github.io/studentos-ai/alt/halloween/event/rewards.html
หน้าเดียวเปิดได้โดยไม่ต้องเข้าสู่ระบบ กด “แชร์ให้ทีม” เพื่อคัดลอกลิงก์ ใช้หน้าแอปจริงในห้องลอง แต่ข้อมูลเป็นตัวอย่างในหน่วยความจำ ไม่เขียนงาน สิทธิ์รางวัล หรือ Candy ของบัญชีจริง

## ของที่ทำไว้

28 แบบ: ของแต่งห้อง 8, ชุด Rare 2, ธีม 5, เอฟเฟกต์ 8, วัตถุ Mystical 4 และเหรียญซื้อครบ 1

- น้องไซแม่มดและฮูกมัมมี่มาจากพิธีอัญเชิญ มีฉากอัญเชิญก่อนลองชุด
- ธีมหลัก Midnight Academy เปลี่ยนฉาก คอมโพเนนต์ ไอคอน มาสคอต มีเสียงและเพลงที่ผู้ใช้เปิดเองได้
- ธีม Dutchman / Jack’o Lantern / Vampire Mansion / Eternal Graveyard มีฉากและสีแยกกัน
- เป้าหมายองค์ประกอบสี 60% พื้นหลังกลางคืน / 30% พื้นการ์ด / 10% จุดเด่น ปุ่มหลัก กรอบระดับ และรายละเอียด การนับนี้เป็นแนวทางออกแบบ ไม่ใช่คำอ้างว่าทุกหน้ามีพื้นที่พิกเซลตรงสัดส่วน
- ระดับภาพ Common/Uncommon/Epic/Legendary/Secret ที่ยังไม่ยืนยันเป็นข้อเสนอสำหรับเทียบความพิเศษ ไม่ใช่เรทดรอปหรือราคา ชุด Rare และ Mystical จาก NPC เป็นกติกาที่เจ้าของกำหนด

## โครงสร้างและการปิดอีเวนต์

- event/: หน้ากิจกรรม ห้องลอง และข้อมูลเควส รับของจริงยังไม่เปิด (config.json claimingEnabled:false)
- rewards/: แค็ตตาล็อก ภาพ ธีม เอฟเฟกต์ และการแสดงรางวัลถาวร
- docs/: บทเควสและทิศทางภาพ
- tests/: ชุดตรวจเสียง แอนิเมชัน ข้อมูล และการแยกบัญชี
- tools/: สร้างภาพ SVG / รายการแคช / เอกสารเควส

ปิดกิจกรรมโดยตั้ง event/config.json enabled:false แล้วลบ event/ ได้เมื่อหมดช่วงกิจกรรม รักษา rewards/ และ cache-manifest.js ไว้ให้รางวัลเดิมใช้งานต่อได้ event/ ไม่อยู่ในรายการแคชติดตั้ง โค้ดหลักมีเพียงจุดโหลดและทะเบียนธีม ระบบสิทธิ์เป็นเจ้าของยังต้องเชื่อมก่อนเปิดรับของจริง ห้ามลบรางวัลถาวรที่ผู้เล่นได้รับ

## เควสที่ยืนยันและสิ่งที่รอรายละเอียด

- [Tang The Sailor](docs/quests.dutchman.md): โคมใช้ Abyssal rock ×1 + Dutchman's Lantern ×1 + 50 Candy; เควสสุดท้าย 2 เฟสให้ Greater Spear + ธีม Dutchman
- [Jack’o Tigger](docs/quests.jack.md): Q1 เปิด Plot; Grow a Garden ปลูก Pumpkin เอง 3 ชิ้นใช้ส่ง Q2; Q3 เลือกของหรือ 200 Candy แล้วต้องส่ง His head อีกครั้งจึงได้ขวานและธีม
- [Mr. Dech](docs/quests.vampire.md): Cruor Quill จาก Q1; Q2 ผ่านจับผิดภาพในบ้านเดช 1 ครั้ง; รอไบโอมวนมาวัฏจักรถัดไปจึงรับ Q3 ซึ่งให้ 100 Candy + ธีมคฤหาสน์
- เวลาโต การรดน้ำ ผลผลิตฟักทอง แหล่ง Shovel จำนวนวัตถุดิบ Dech Q2/Q3 และผลของ Totem ต่อเงื่อนไขวัฏจักรยังไม่ระบุ ไม่ตั้งกติกาแทนเจ้าของ

บทพูดและเงื่อนไขฉบับข้อมูลอยู่ event/data/quests.*.json ส่วน materials.json แยกเรทบ้านออกจากการรับรางวัลถาวร

## ตรวจและสร้างไฟล์

จากราก repo ใช้ Node โดยไม่ต้องติดตั้งแพ็กเกจ:

~~~text
node --test --test-isolation=none alt/halloween/tests/*.test.mjs
node alt/devtools/scene-check.cjs
node alt/devtools/sw-check.cjs
node alt/halloween/tools/build-art.cjs
node alt/halloween/tools/build-cache.cjs
node alt/halloween/tools/sync-specs.cjs
~~~

เครื่องมือตรวจจอ /alt/device-preview.html เป็นของ ALT ทุกธีม แยกจากกิจกรรม Halloween

ข้อจำกัด: ห้องลองทำภาพ/เสียง/การสวมรางวัล ไม่ได้เปิดบ้าน เควสจริง ร้านแลก Candy หรือการสุ่มรับของ ยังไม่อ้างผล FPS หรือการทดสอบฮาร์ดแวร์มือถือจริง

## ผลตรวจรอบนี้

- Halloween 18/18; service worker 6/6; ฉาก 170 กฎ; บัญชี 33/33; ซิงก์ 36/36
- เบราว์เซอร์: คอลเลกชัน 375 / 820 / 1440 ไม่มีส่วนเกินแนวนอน ตัวกรองธีม 5 และ Secret 1 ตรงรายการ
- ลองธีมทั้ง 5 ชุดทั้ง 2 เอฟเฟกต์ทั้ง 8 และของห้องหลายช่อง พร้อมหน้าดู Mystical/เหรียญ ไม่มี console error ที่บันทึกในรอบ QA
- มือถือจำลอง 375×812 เปิดภาพได้ เห็น transform ของฉากและผีเปลี่ยนตามเวลา หน้าแรกไม่มี scroll แนวนอนหรือแนวตั้ง; ทดสอบปุ่มแท็บเล็ตและคอมด้วย
- ไม่ได้วัด FPS หรือยืนยันเสียงด้วยหูบนฮาร์ดแวร์มือถือจริง ยังไม่เปิดรับรางวัลจริง


## เลือกใช้ใน ALT

- ธีม 5 แบบ: ฉัน → ตั้งค่า → ธีมสี
- ชุด 2 แบบ: ฉัน → ตั้งค่า → ผู้ช่วย AI → ชุดมาสคอต Halloween; เลือกชุดสลับตัวช่วยตามชุด และจำค่าในเครื่อง ใช้ปุ่ม “ใช้ชุดตามธีม” คืนค่าได้
- เอฟเฟกต์ 8 แบบ: ฉัน → ตั้งค่า → ธีมสี → เอฟเฟกต์ตอนงานเสร็จ เลือกก่อน แล้วกดลองเล่นดูหรือทำงานให้เสร็จ
- ของแต่งห้อง 8 ชิ้น: ห้องของฉัน → บนโต๊ะ / ชั้น / โปสเตอร์ / เพดาน / บนพื้น ใช้ช่องและการบันทึกห้องเดิม

รอบนี้เจ้าของสั่งเปิดของตกแต่งทั้งหมดบน ALT จึงเลือกใช้ได้โดยไม่หัก Candy/โทเคน ไม่สุ่มและไม่สร้างรายการเป็นเจ้าของในคลังอีเวนต์ โค้ดอยู่ rewards/integration.js และมีจุดเชื่อมเล็ก ๆ ใน sai.js, hoop.js, index.html ธีมกับเอฟเฟกต์ที่เลือกใช้คีย์เดิม ชุดใช้คีย์ใหม่ studentos.alt.halloween.costumes; ของห้องอยู่ settings.room เดิม

|---|---|
| รอยคลื่นวิญญาณ | จุดโคมนำทาง 1 → 2 → 3 |

| ปีกกำมะหยี่ | ลากใบงานไปให้ค้างคาว |

| Jack’s Final Verdict | ลากเคียวฟันผ่านใบงาน 3 ครั้ง ใบงานแตก 8 ชิ้น |
| Crimson Eclipse | แตะจัดเงาจันทร์ให้ซ้อนกัน 3 ชั้น |

มีปุ่มแทนท่าทางสำหรับคีย์บอร์ด ข้าม/Escape ได้ตลอด งานบันทึกก่อนเปิดเกม รอเกมจบหรือข้ามจึงแสดงงานถัดไป ไม่ให้ Candy หรือไอเทมจากการเล่นเอฟเฟกต์ การเล่นไม่ใช่มินิเกมเควส NPC

ยึดการลดการเคลื่อนไหวของผู้ใช้ มีปุ่มเปิด/หยุดภาพภายในเกม หากลดภาพยังเล่นได้และเห็นเศษกระดาษแยกแบบนิ่ง

## สายเควสครบทั้ง 4 NPC

[Win, the Soul Reaper](docs/quests.graveyard.md) มี 5 เควส: Q1 ให้ Shovel (แหล่งพลั่วของ Jack ได้ข้อยืนยันแล้ว); Q2 ขุดหลุมหนึ่งรอบแล้วจับผีทั้งหมดใน 30 วินาที; Q3 ได้ Blade Phase; Q4 ได้เคียว Restricted เฉพาะ Eternal Graveyard; Q5 จ่าย 50 Candy และแสดง Dutchman’s Soul โดยไม่หักของ เพื่อปลดข้อจำกัดของเคียวชิ้นเดิมถาวรพร้อมธีม Eternal Graveyard รายละเอียดครบใน event/data/quests.graveyard.json

## ตรวจรอบเพิ่มการใช้งานจริง

- Halloween 26/26, service worker 6/6, ฉากต่อเนื่อง 170 กฎ
- เบราว์เซอร์ข้อมูลจำลอง: ชุดจำค่าข้าม reload และยังอยู่หลังสลับธีม; ของห้องทั้ง 8 เลือกได้และบันทึกข้าม reload
- เล่นเอฟเฟกต์ทั้ง 8 จนจบ รวมลากงาน 3 แบบและลากเคียวจริง; ตรวจว่าฟันครบแล้วเกิดเศษใบงาน 8 ชิ้น
- ทำงานเสร็จแล้วเล่นจนจบ และทำงานเสร็จแล้วข้าม กลับมาเห็นงานถัดไปถูกต้อง ไม่มี error ที่บันทึกบน QA พอร์ตใหม่
- พื้นที่เกม 375×812, 820×1180, 1440×900 ไม่ล้น ปุ่มข้ามอยู่ในจอ ไม่ได้อ้างผล FPS หรือทดสอบฮาร์ดแวร์สัมผัสจริง


### ห้องลองระหว่างอัปเดตเว็บ

app.js ล้างคิวรีทั่วไป แต่คงคิวรีห้องลองไว้ ธง __STUDENTOS_HALLOWEEN_COLLECTION__ บนหน้าแม่ยังยืนยันโหมดจำลองได้หลัง iframe ถูก service worker รีโหลด ห้ามพึ่งคิวรีเพียงอย่างเดียว และห้ามใช้ localStorage จริงบันทึกธงโหมดนี้
