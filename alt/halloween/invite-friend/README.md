# Invite Friend · ชวนเพื่อนปลดล็อกธีม Halloween

ชวนเพื่อนที่ **ไม่เคยใช้ StudentOS** มาใช้ด้วยรหัสเชิญ ลิงก์ หรือ QR · ครบสองภารกิจแล้วได้ธีม Halloween

1. ชวนเพื่อนครบ 3 คน (นับที่เซิร์ฟเวอร์)
2. ทำงานในแอปเสร็จ 1 งาน (นับในเครื่อง · จดไว้ที่ `funnel.hwTaskAt` ซิงก์ข้ามเครื่องได้)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `invite-friend.js` | ทั้งระบบฝั่งแอป: เก็บรหัสจากลิงก์ `?invite=` · ใช้รหัสหลังล็อกอิน · แผ่นชวนเพื่อน · วาด QR · นับภารกิจ · ฉลองปลดล็อก · การ์ดในจอเพื่อน |
| `invite-friend.css` | หน้าตาโทนคืนฮาโลวีนของแผ่นชวนเพื่อนกับการ์ด (โทเคนสีอยู่ใน `.iv-sheet` / `.iv-entry` ไม่แตะธีมของแอป) |
| `qrcode-generator.js` | ตัวสร้าง QR (Kazuhiko Arase · MIT) โหลดเฉพาะตอนเปิดแผ่นครั้งแรก |

ไฟล์ที่ต้องอยู่นอกโฟลเดอร์นี้ (ย้ายเข้ามาไม่ได้):

- `supabase/migrations/20261023150000_invites.sql` — ตาราง + `my_invite()` + `redeem_invite()` · Supabase อ่าน migration จาก `supabase/migrations/` เท่านั้น
- `supabase/tests/invites.test.mjs` — เทสต์กติกากับ Postgres จริง (PGlite) · วิธีรันอยู่หัวไฟล์
- จุดต่อใน `alt/app.js`: `funnelDone()` · `funnelMerge()` · `themePref()` · `setTheme()` · `themeLocked/themeOwned/themeVisible/applyThemeLocks` · ล็อกอิน (`initCloud`) · `renderFriends()` — ทุกจุดเรียกผ่าน `typeof … === 'function'` ถอดโฟลเดอร์นี้ออกแอปก็ไม่พัง
- `alt/index.html` โหลด `invite-friend.css` กับ `invite-friend.js` (ก่อน `app.js`) · แคชออฟไลน์ผ่าน `halloween/cache-manifest.js` (สร้างใหม่ด้วย `node halloween/tools/build-cache.cjs`)

## กติกา (บังคับใน `redeem_invite` ที่เดียว)

- นับเฉพาะคนที่ไม่เคยใช้ StudentOS: บัญชีสร้างไม่เกิน 7 วัน และวันแรกที่เปิดแอปต้องไม่ก่อนวันสมัครเกิน 1 วัน
- บัญชีหนึ่งถูกชวนได้ครั้งเดียว · ใช้รหัสตัวเองไม่ได้ · คนที่บล็อกกันใช้ไม่ได้ · รหัสหนึ่งใช้ได้ 6 คน
- ใช้รหัสแล้วเป็นเพื่อนกันทันที
- ที่ยังกันไม่ได้: คนเดิมสมัครบัญชีที่สองบนเครื่องที่สลับบัญชี

## ต่อกับธีม (เพื่อนในทีมกำลังทำหน้าตา)

ธีมที่ภารกิจนี้ปลดใช้ id **`hw-invite`** (`INVITE_THEME` ใน `invite-friend.js`) · เพิ่มธีมด้วย id นี้ตามกฎ "เพิ่มธีมใหม่ต้องแก้ 3 ที่" ใน `AGENTS.md` แล้วปุ่มธีมจะขึ้นกุญแจ กดแล้วเปิดแผ่นภารกิจจนกว่าจะครบเอง · สคริปต์ใน `<head>` ของ `index.html` ต้องไม่วาดธีมนี้ถ้ายังไม่ปลดล็อก

## ก่อนเอาขึ้นเว็บ

รัน `supabase/migrations/20261023150000_invites.sql` ใน Supabase **ก่อน** merge เข้า `main` · ถ้ายังไม่รัน แผ่นจะขึ้น "ยังสร้างรหัสเชิญไม่ได้" พร้อมปุ่มลองใหม่ (แอปไม่พัง)
