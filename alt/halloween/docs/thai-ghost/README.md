# เรือนลับแล · ย้ายรางวัลชวนเพื่อน · 25 ตุลาคม 2569

เจ้าของขอให้ Halloween และ Moon & Candle ไม่ติดเงื่อนไขชวนเพื่อนหลังจบอีเวนต์ จึงย้าย INVITE_THEME จาก halloween เป็น thai-ghost และสร้างธีมผีไทยชื่อเรือนลับแล ปุ่มทั้งสองธีมของบอสไม่ถูก inviteThemeGate ดักอีก การให้รางวัลธีมคู่และตราหลังบอสยังใช้ระบบเดิม ไม่มีการเพิ่มรางวัลหรือเปลี่ยนกติกาบอส

เงื่อนไขเรือนลับแลคงเดิม: เพื่อนใหม่ 3 คนจาก redeem_invite/my_invite และงานสำเร็จ 1 งานจาก funnel.hwTaskAt ใช้แคชที่ผูกบัญชีและข้อมูลเดิมทั้งหมด ไม่รีเซ็ตยอด ไม่นับคลิกลิงก์เป็นเพื่อน ไม่เปลี่ยนคีย์ studentos.alt.* ค่าบันทึกการฉลองเดิมเพิ่มชื่อธีมในค่าเพื่อให้ผู้ที่ทำครบแล้วเห็นการฉลองรางวัลใหม่ครั้งเดียว ไม่แก้ schema, RPC, หรือบริการบัญชี รางวัลตกแต่งยังอยู่บนกลไกสิทธิ์ของแอปเดิม ไม่อ้างว่ามีใบรับรองรางวัลแบบใหม่จากเซิร์ฟเวอร์

ภาพเป็น SVG ของเรือนยกพื้น จั่วไม้ ลายดอกบัว สวนกล้วย รากไทร และจันทร์ดับ โทนเขียวหมึกกับทองเก่า ปุ่มและการ์ดเปลี่ยนทั้งแอปโดยไม่แก้สีระดับความสำคัญ ฉากเพิ่มหมอกธูป หิ่งห้อยเจ็ดจุดและเงาผีผมยาว ใช้เฉพาะ transform/opacity หยุดเมื่อซ่อนแท็บ ลดการเคลื่อนไหว หรือโหมดเครื่องเบา ไม่มีเสียงเปิดเอง หน้าธีม/หน้าเพื่อน/หน้ากิจกรรมเปลี่ยนชื่อรางวัลตรงกัน สมุดในเกมถอดข้อความเก่าว่ายังไม่มีระบบชวนเพื่อนและชี้ไปหน้าภารกิจจริง

ปุ่มลองธีมเปิดแอปใน iframe ที่มี memory storage ของ fitting room เดิมและปิดการเชื่อมบัญชี ไม่มีการบันทึกธีมลงบัญชีจริง เฟรมใช้ขนาด 375×812 แล้วย่อพอดีกับพื้นที่แสดง ไม่ตัดปุ่มเมื่อจอเล็ก ปิดแล้วคืนโฟกัสและข้อมูลเดิม

ตรวจแล้ว:

- Halloween 183/183 รวม regression ใหม่ห้าข้อ เรื่องแยก gate, ความคืบหน้าเก่า, เจ้าของแคช, ห้องลอง และคอนทราสต์ข้อความ 4.5:1; เห็นชุดใหม่ตกก่อนแก้ (RED)
- Sync 36/36, account 33/33, service worker 6/6 และฉาก 207 กฎผ่าน
- เบราว์เซอร์ผู้ใช้ใหม่ที่ไม่ล็อกอิน/ชวนศูนย์คน: Halloween และ Moon & Candle ใช้ได้โดยไม่เปิดหน้าชวนเพื่อน; เรือนลับแลเปิดแผ่นภารกิจ 0/3 + 0/1
- เปิด/ปิดห้องลองจากภารกิจจริงแล้วธีมหลักยังเป็น light; ทดสอบหน้าโฮมของธีมใหม่ที่ 375×812 ไม่เลื่อนและไม่ล้นแนวนอน
- ห้องลอง 320×568 ไม่ล้น ปุ่มปิดอยู่ในจอ; ภาพหลักฐาน home-375.png, fitting-room-375.png, quest-375.png

ไม่ได้สร้างบัญชีหรือส่งคำเชิญจริงใน QA รอบนี้ ไม่อ้างว่าทดสอบการชวนระหว่างผู้ใช้จริงใหม่ เลขแอปคง 1C60 เปลี่ยนเฉพาะชื่อแคชเพื่อส่งไฟล์ตกแต่ง

## 25 ตุลาคม 2569 · ระนาด ภาพเคลื่อนไหว และหมวดความหายาก

- เพิ่มเงาผีสองระยะ เครื่องรางไกว แสงหน้าต่าง หมอกหลายชั้น รัศมีจันทร์ หิ่งห้อยเก้าจุด และลายดอกบัวบนการ์ด ฉากใช้ transform/opacity และมีสวิตช์หยุดภาพของเรือนลับแลแยกจาก Halloween เคารพโหมดลดการเคลื่อนไหวตามระบบจนกว่าจะเลือกเปิดเอง

## 26 ตุลาคม 2569 · "จันทร์หยก" แทนฉากเวกเตอร์

เจ้าของปฏิเสธเขียวหมึกเดิม แนวผีไทยหลอนจัด และฉากเวกเตอร์ที่วาดด้วยโค้ด แล้วส่งภาพวาดเรือนไทยกลางสระใต้จันทร์เสี้ยวมาเอง (สร้างด้วย ChatGPT ตามพรอมต์ในเซสชัน) ภาพอยู่ที่ invite-friend/jade-moon.webp (852×1847 · 105KB) โหลดเมื่อ mount ฉากเท่านั้น thai-estate.svg ยังอยู่ในแคชแต่ไม่ถูกใช้ในฉากแล้ว

สีตามสเปก "Jade Moon": หัวการ์ด #174E39 · แสงจันทร์ #D8E8C9 (ปุ่มหลัก/แท็บที่เลือก) · กระจก --tg-glass #0B2219D1 ซึ่งคำนวณให้ --muted ≥ 4.5 แม้พื้นหลังใต้กระจกเป็นสีขาว ไม่มีผี/เครื่องราง/ลายบัว (decorate() ถูกถอด) โคมลอยที่ขยับมีสามดวง ไม่รับคลิก ระนาดเปลี่ยนเฉพาะ score และ envelope เครื่องเดิมทั้งหมด (เปิดเอง ยกเลิก resume ค้าง ไม่ไล่ทำนองค้าง) ไม่เปลี่ยน
