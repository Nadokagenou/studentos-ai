# เรือนลับแล · ย้ายรางวัลชวนเพื่อน · 25 ตุลาคม 2569

เจ้าของขอให้ Halloween และ Moon & Candle ไม่ติดเงื่อนไขชวนเพื่อนหลังจบอีเวนต์ จึงย้าย INVITE_THEME จาก halloween เป็น thai-ghost และสร้างธีมผีไทยชื่อเรือนลับแล ปุ่มทั้งสองธีมของบอสไม่ถูก inviteThemeGate ดักอีก การให้รางวัลธีมคู่และตราหลังบอสยังใช้ระบบเดิม ไม่มีการเพิ่มรางวัลหรือเปลี่ยนกติกาบอส

เงื่อนไขเรือนลับแลคงเดิม: เพื่อนใหม่ 3 คนจาก redeem_invite/my_invite และงานสำเร็จ 1 งานจาก funnel.hwTaskAt ใช้แคชที่ผูกบัญชีและข้อมูลเดิมทั้งหมด ไม่รีเซ็ตยอด ไม่นับคลิกลิงก์เป็นเพื่อน ไม่เปลี่ยนคีย์ studentos.alt.* ค่าบันทึกการฉลองเดิมเพิ่มชื่อธีมในค่าเพื่อให้ผู้ที่ทำครบแล้วเห็นการฉลองรางวัลใหม่ครั้งเดียว ไม่แก้ schema, RPC, หรือบริการบัญชี รางวัลตกแต่งยังอยู่บนกลไกสิทธิ์ของแอปเดิม ไม่อ้างว่ามีใบรับรองรางวัลแบบใหม่จากเซิร์ฟเวอร์

ภาพเป็น SVG ของเรือนยกพื้น จั่วไม้ ลายดอกบัว สวนกล้วย รากไทร และจันทร์ดับ โทนเขียวหมึกกับทองเก่า ปุ่มและการ์ดเปลี่ยนทั้งแอปโดยไม่แก้สีระดับความสำคัญ ฉากเพิ่มหมอกธูป หิ่งห้อยเจ็ดจุดและเงาผีผมยาว ใช้เฉพาะ transform/opacity หยุดเมื่อซ่อนแท็บ ลดการเคลื่อนไหว หรือโหมดเครื่องเบา ไม่มีเสียงเปิดเอง หน้าธีม/หน้าเพื่อน/หน้ากิจกรรมเปลี่ยนชื่อรางวัลตรงกัน สมุดในเกมถอดข้อความเก่าว่ายังไม่มีระบบชวนเพื่อนและชี้ไปหน้าภารกิจจริง

ปุ่มลองธีมเปิดแอปใน iframe ที่มี memory storage ของ fitting room เดิมและปิดการเชื่อมบัญชี ไม่มีการบันทึกธีมลงบัญชีจริง เฟรมใช้ขนาด 375×812 แล้วย่อพอดีกับพื้นที่แสดง ไม่ตัดปุ่มเมื่อจอเล็ก ปิดแล้วคืนโฟกัสและข้อมูลเดิม
