# เก็บรายละเอียดก่อนเปิดอีเวนต์ · 26 ตุลาคม 2569

เจ้าของแจ้งว่าปุ่มเข้าสวนถูกป้ายภารกิจบัง และยืนยันว่าเล่นแล้วเซฟทำงานดี งานนี้แก้ UI/ทางเข้าและข้อความ ไม่ล้างเซฟ ไม่เปลี่ยนคีย์ กติกา หรือรางวัล และคงเลขแอป 1C60

- ย้ายภารกิจตอนนี้เป็นปุ่ม 44px ด้านบน กดเปิดรายละเอียด/ปิดได้เอง ไม่มีการ์ดบังคับปิดทับแผนที่ ป้ายทองบอกเป้าหมายยังอยู่ ปุ่มจุดกดอย่างน้อย 44px
- ใช้คำสอนเวสเปอร์ใหม่ให้ตรงตำแหน่งปุ่ม นับเวลาประตูในกล่องภารกิจได้ด้วย
- แก้ลิงก์เข้าบัญชีจาก event/vault เป็น go=login รองรับทั้ง root และ ALT รวม go=profile เก่า ผ่านตัวเปลี่ยนจอเดิม หลังยืนยันบัญชีแล้วไม่ย้อนกลับ login
- หน้าอีเวนต์ที่ยังไม่เปิด/จบแสดงสถานะตามจริง แยกข้อความ Candy/สวน/สูตรจริงกับห้องลอง ปุ่มออกกลับแอปรุ่นที่เข้ามา
- เปลี่ยนชื่อแคชแยก root/ALT และ revision เฉพาะไฟล์อีเวนต์ที่แก้ ไม่เปลี่ยน APP_VERSION
