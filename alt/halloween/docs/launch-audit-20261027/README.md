# ตรวจอีเวนต์ก่อนเปิด · 27 ตุลาคม 2569

ผลตรวจรอบก่อนเปิดและส่วนแก้ในแพตช์นี้ · คง1C60 เซฟ/เพลง/กติกา/วันเปิดเดิม

## สิ่งที่พบและแก้

1. ท้ายสมุดรัตติกาลติดคำว่า “ห้องลอง” ในโหมดบัญชีจริง เปลี่ยนให้รับpreviewจากทางเข้าจริง โหมดจริงแสดงผูกบัญชีStudentOS ห้องลองยังระบุแยกชัด
2. กติกาหน้าร้านเรียกสต็อกจริงว่า “ทดลอง” และ “เซฟห้องลองนี้” แก้ให้ตรงบัญชีและฤดูกาล โดยไม่เปลี่ยนราคา จำนวน หรือผลสุ่ม
3. วิธีเล่นบอกตำแหน่งภารกิจว่าอยู่ด้านล่าง แก้เป็นปุ่มภารกิจด้านบนตามหน้าจอที่ใช้จริง
4. ชั้นสินค้าและquoteร้านใช้Date.nowของเครื่อง แต่เวลานับถอยหลังอิงบริการบัญชี ทำให้เครื่องเวลาคลาดเคลื่อนอาจเห็นคนละรอบ แก้ให้ทั้งสองใช้clockNowที่ปรับจากเซิร์ฟเวอร์ โดยtimeOffsetของห้องลองยังถูกบวกครั้งเดียว

เทสต์ใหม่3กรณีเห็นล้มก่อนแก้แล้วผ่าน: live/trialสมุดและตำแหน่งปุ่ม, live/trialร้าน, ซื้อของเมื่อเครื่องเร็ว1ชั่วโมง รวมกรณีมีpreview timeOffset

## ลองหน้าจอจริงในห้องลอง

- ประตู → โถงกลาง → เวสเปอร์ → สวนฟักทอง → คุยNPCเปิดใบเควสและแหล่งของ
- ปุ่มสวนแตะเข้าได้ ไม่ถูกป้ายภารกิจบัง ปลูกเมล็ด1 รดน้ำ รอเวลา1นาทีตามเกม เก็บได้ฟักทอง3ในกระเป๋าห้องลอง ไม่ใช้เร่งเวลาและไม่แจกให้บัญชีจริง
- จากสวนไปพ่อค้า หยิบฟักทองวางตาชั่งแล้วคืน ยอดCandy0และผลผลิต3ไม่ถูกหักก่อนยืนยัน
- สนามฝึกสามท่า: หลบซ้าย → ตั้งรับ → ยึดสมอ จบ3/3 มีคำอธิบายไม่แจกCandyหรือรางวัลบอส
- เกมพักสมอง: หม้อปรุงยา3โจทย์ จบแล้วสุ่มอีกแบบเป็นสะพานเรือผี เดินถึงท่าเรือและจบได้ มีข้อความไม่เพิ่มCandyจากการเล่นซ้ำ
- สมุดเส้นทางมีหลอดความคืบหน้าทั้ง4ไบโอม คลัง/ภารกิจ/วิธีเล่นเปิดถึงกันได้
- 320×568,375×812,812×375,1024×768: ไม่มีล้นแนวนอน หน้าต่างที่ตรวจอยู่ในviewport และไม่พบรูปแตกจากDOMที่โหลดแล้ว
- ประตูเว็บจริงที่ไม่มีpreviewยังแสดงวัน28ต.ค.–30พ.ย.และ “เชื่อมบัญชีแล้ว · พบกันเมื่อประตูเปิด” ไม่มีการฝืนเวลาเปิดเพื่อทดสอบรับของ

## ขอบเขต

ไม่ได้เล่นด้วยบัญชีจริงจนจบอีเวนต์ก่อนวันเปิด ไม่แจกของทดสอบ ไม่ล้างบัญชี ไม่อ้างการทดสอบคนจำนวนมาก/สองอุปกรณ์จริง/ป้องกันบอต100% การส่งเควสและบอสท้ายเกมตรวจด้วยfixtureและชุดกติกาอัตโนมัติ ไม่อ้างว่าเดินเนื้อเรื่องจริงทุกเฟสด้วยมือรอบนี้

แท็บiframeQAมีconsole MutationObserver.observe หนึ่งรายการไม่มีตำแหน่งsource เช่นเดียวกับfixtureก่อนหน้า ขณะที่แท็บประตูเว็บจริงไม่มีerror/warning และไฟล์eventที่โหลดไม่ได้สร้างMutationObserver ไม่แก้โค้ดแอปจากการเดาสาเหตุของเครื่องมือตรวจ
