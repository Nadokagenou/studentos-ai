# สมุดรัตติกาลและ NPC แนะนำ · 24 ตุลาคม 2569

สถานะ: พรีวิวในเครื่อง ยังไม่ commit/push รอบนี้ เลขแอปคง 1C60

ตามคำขอเจ้าของ เปลี่ยนแถบปุ่มล่างหกปุ่มเป็นสมุดพกหนึ่งเล่มมุมขวาล่าง เปิดอ่านสารบัญ เควส กระเป๋า เส้นทาง และวิธีเล่นได้ ปุ่มสวน น้ำยา Totem และงานตัวอย่างอยู่ในหน้าสมุด ทางกลับ StudentOS อยู่บนหัวสมุดด้วย

เวสเปอร์ยืนข้างทางเดินในโถงกลาง แตะจุดแดงครั้งเดียวเพื่อคุยและเปิดคู่มือ เริ่มครั้งแรกเห็นคำเชิญสั้น ๆ แทนหน้าคู่มือบังคับเปิด บทคุยเดิมของเวสเปอร์ที่วงเวทและ NPC เควสทุกคนคงเดิม ไม่มี NPC เควสใหม่หรือรางวัลสอนเล่น

สมุดใช้รายการเควส/กระเป๋าและตัวจัดการการเดินทางเดิม รายละเอียดของมีปุ่มกลับหน้าสมุด เลือกหน้าด้วยคีย์บอร์ดได้ Escape พับกลับฉากและคืนโฟกัสที่ปุ่มสมุด ส่วนหัว ที่คั่นหน้า และปุ่มพับอยู่บนจอตลอด อ่านเนื้อหายาวด้วยการเลื่อนกระดาษ

แก้หมุดประตูบนมือถือจากวงรี 24×13 เป็นวงกลม 13×13 โดยคงพื้นที่กดของประตู และตรวจตำแหน่งเวสเปอร์ไม่ทับปุ่มสถานที่อื่น

## ผลตรวจ

- Halloween เดิม 110/110 ผ่านด้วย `node --test --test-isolation=none alt/halloween/tests/*.test.mjs` (ใช้โหมดนี้เพราะ sandbox ไม่อนุญาต spawn ของ test runner)
- Syntax ของ experience.js, world.js, journal.js และ git diff --check ผ่าน
- สมุด 5 หน้า × 10 ขนาด = 50 ชุด ไม่พบแนวนอนล้น ภาพเสีย หน้าต่างเกินจอ หรือปุ่ม/ลิงก์เล็กกว่า 44px โฟกัสอยู่ที่หน้าที่เลือก
- โถงกลาง 10 ขนาด: มีสมุด 1 เล่ม ไม่มี dock เดิม หมุดประตู 13×13 และพื้นที่ NPC ไม่ทับสถานที่/สมุด ดู [รายงานขนาด](journal-layout-2026-10-24.json)
- ขนาดที่ตรวจ: 320×568, 375×812, 390×844, 812×375, 844×390, 768×1024, 1024×768, 1280×720, 1440×900, 2560×1080
- ลอง UI จริง: เปลี่ยนหมวดวัตถุดิบ/บัญชี Candy → เปิดของ → กลับหน้าสมุด; NPC → คู่มือ → สมุดเควส → ไบโอม → บทนำเดิม → สำรวจ เซฟใหม่ยัง 0 Candy ไม่ได้รับของจากการสอน ไม่พบ console error
- ยังไม่เชื่อมงานหรือ Candy บัญชีจริง ไม่แก้กติกา รางวัล คูลดาวน์ เซฟ คีย์ หรือ claimingEnabled
