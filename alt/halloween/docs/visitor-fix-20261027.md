# นักเดินทางในม่านหมอก · 27 ต.ค. 2569

ภาพจากผู้เล่นแสดงพื้นเหลืองและด้านขวาของ dialog ถูกตัด สาเหตุคือ `#fff01a` เป็นสีทึบเหลือง ไม่ใช่ขาวโปร่งใส และ grid/flex มีความกว้างขั้นต่ำตามข้อความ

แก้พื้นม่วงสองระดับ ข้อความครีม/ม่วงอ่อน พร้อมการห่อข้อความและ min-width:0 ใน card/grid/dialog หัว dialog ใช้ layout มือถือเดิม ปุ่มส่งของมีเป้าสัมผัสอย่างน้อย 44px ไม่แก้ธุรกรรมหรือจำนวนของ

ทดสอบ contrast regression: เห็นล้มก่อนแก้ แล้วผ่านหลังแก้ รวม palette 11/11 ตรวจ DOM ของ popup ผ่านเส้นทางเล่นจริงในห้องลอง ไม่รีเซ็ตเซฟ:

| หน้าจอ | dialog | ล้นแนวนอน | อยู่ในจอ |
|---|---|---|---|
| 320×568 | 304×518 | ไม่ | ใช่ |
| 360×800 | 344×518 | ไม่ | ใช่ |
| 375×812 | 359×497 | ไม่ | ใช่ |
