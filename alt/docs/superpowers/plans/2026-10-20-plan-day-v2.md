## Task 4: Set a task's time yourself

Files: `alt/engine.js` (`buildDayPlan`, starting line 1136), `alt/sai.js` (the Task 2 sheet), `alt/alt.css`, a new check file. **This is the risky task — engine output feeds every screen.**

Data: optional task field `pinAt` (ISO string, local time today). Set only by the UI below; clearing = delete the field.

Engine rules in `buildDayPlan` (keep everything else byte-for-byte the same in behaviour):
1. A pin counts only if `pinAt` is today (same local date as `now`), the task is still pending and schedulable, and `pinAt + its need` has not already passed. Anything else: ignore the pin (behave as if unpinned).
2. A counted pin must fall inside one of `win.slots` (the free windows, minutes since midnight). If it does not, ignore it.
3. Placed pins become fixed slots: start = max(pinAt, now), length = min(need, minutes left in that window, remaining day budget). Mark the slot `pinned: true`. Pinned tasks leave the normal queue; their minutes count against the day budget.
4. Run the existing allocation loop over the free windows **with the pinned intervals cut out** (split each window around them), so other tasks fill the gaps exactly as today. Then merge pinned slots into `slots` and sort by start.
5. Overflow / missed logic and the mustToday ordering stay as they are for the unpinned tasks.
- Add a Node-runnable test `alt/devtools/pin-check.cjs` (load the real `engine.js` (and whatever it needs) into a `vm` context the way the other `.cjs` checks in `alt/devtools/` do) covering: no pins → identical slots to before; a pin inside a window lands exactly there and others fill around it; a pin outside every window is ignored; a stale pin is ignored; two pins in one window both land; budget is respected. Print `pin-check: P/T`.
- All engine benches must stay green (benchParse, benchFacts, benchDecide, benchRisk, benchProfile in allchecks).
UI:
- In the Task 2 sheet add "ตั้งเวลาเอง": shows time chips for today — "ตอนนี้" plus the next 15-minute marks inside free windows (from `dayWindows`/`freeSlots` data already used by the plan), up to 8 chips.
