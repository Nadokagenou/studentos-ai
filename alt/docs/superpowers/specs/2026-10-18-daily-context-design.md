# บริบทรายวัน + ปิดเทอม — สเปก

วันที่ 18 ต.ค. 69 · เจ้าของอนุมัติแบบในแชทแล้ว (ม็อกอัปสามจอ: แถบหน้าแรก · การ์ด AI · คำถามปิดเทอม)

## ปัญหา

1. **ปิดเทอมแล้วแต่แอปยังวางคาบเรียน** — `busyBlocks(date)` (context.js) เลือกคาบจากวันในสัปดาห์อย่างเดียว
   ไม่มีแนวคิด "ช่วงที่ตารางนี้ใช้" แผนรายชั่วโมง · ไทม์ไลน์ · ปฏิทิน · เวลาว่าง ผิดพร้อมกันหมด
   และ `aiContext()` ส่งตารางเรียนทุกคาบให้น้องไซเสมอ AI จึงจัดตารางชีวิตแบบเปิดเทอม
2. **วันนี้ไม่เหมือนทุกวัน แต่บอกแอปไม่ได้** — บริบทมีแค่ prefs · classes · routines ซึ่งซ้ำทุกสัปดาห์
3. เจ้าของอยากให้ AI ช่วยวิเคราะห์ ไม่ใช่แค่จดเวลา

## หลักที่ห้ามเสีย

- ทุกจอที่ตอบว่า "ควรทำอะไร" ยังอ่านจาก `studyPlan()` ก้อนเดียว · ของใหม่เข้าไปที่ `busyBlocks()` จุดเดียว แล้วทุกจอเปลี่ยนตามเอง
- AI เสนอ คนเคาะ — ไม่มีการเขียนบริบทรายวันโดยที่ผู้ใช้ไม่ได้กดยืนยัน
- AI ไม่ได้เลือกงานแรกแทนเอนจิน · ข้อสังเกตของ AI เป็นคำอธิบายเรื่องเวลา งานแรกยังมาจากแผน
- ไม่เปลี่ยนคีย์ `studentos.alt.ctx` · เพิ่มช่องใหม่ในก้อนเดิม
- ออฟไลน์ / ไม่ได้ล็อกอิน / AI ล่ม → แถบแตะเดียวกับการเลือกเวลาเองยังใช้ได้
- หน้าแรก (`scr-menu`) ต้องไม่ต้องเลื่อนที่ 375×812

## ข้อมูล (context.js)

ก้อน `studentos.alt.ctx` เพิ่มสองช่อง:

```js
breaks: [ { id, from: 'YYYY-MM-DD', to: 'YYYY-MM-DD', title: 'ปิดเทอม' } ]
// to = วันสุดท้ายของการหยุด (วันก่อนเปิดเทอม) · เปิดเทอมวันที่ X → to = X − 1 วัน

days: {
  'YYYY-MM-DD': {
    school: true | false | null,   // null = ตามปกติ (ตามตาราง/ช่วงปิดเทอม)
    away: false,                   // true = ไม่อยู่ทั้งวัน ไม่วางงานเลย
    blocks: [ { start: 'HH:MM', end: 'HH:MM', title } ],   // ช่วงที่ไม่อยู่/ติดธุระ
    note: '',                      // ข้อความที่พิมพ์ (สั้น ≤ 120 ตัว)
    advice: '',                    // ข้อสังเกตของ AI ที่ผู้ใช้กดรับแล้ว (≤ 160 ตัว)
    src: 'tap' | 'ai' | 'manual',
    at: <ms>                       // เวลาที่จด — ใช้ตัดสินตอนซิงก์ชนกัน
  }
}
```

- `ctxLoad` · `ctxImport` · `ctxClear` ต้องรู้จักสองช่องนี้ (ตอนนี้ทั้งสามตัวทิ้งช่องที่ไม่รู้จัก)
- ตัดของเก่าทิ้งตอนบันทึก: `days` เก็บแค่ 14 วันย้อนหลังถึงอนาคต · `breaks` ที่ `to` ผ่านไปเกิน 30 วันลบทิ้ง
- ซิงก์คลาวด์ไปทางเดิมของบริบท (`ctxExport` / `ctxImport`) ไม่มีตารางใหม่

### ฟังก์ชันใหม่

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `ctxDayKey(date)` | 'YYYY-MM-DD' ตามเวลาท้องถิ่น |
| `ctxBreakOn(date)` | คืนช่วงปิดเทอมที่ครอบวันนั้น หรือ null |
| `ctxDay(date)` | คืนบันทึกของวันนั้น หรือ null |
| `ctxSetDay(date, patch)` | เขียน/รวมบันทึกของวัน + ตัดของเก่า + `ctxSave()` |
| `ctxClearDay(date)` | ลบบันทึกของวัน (ปุ่ม "แก้" → กลับเป็นปกติ) |
| `ctxSetBreak(fromKey, toKey)` / `ctxEndBreak()` | ตั้ง/ยกเลิกปิดเทอม (มีได้ช่วงเดียวที่ยังไม่จบ) |
| `ctxSchoolOn(date)` | `day.school` ถ้ามี · ไม่งั้น `!ctxBreakOn(date)` |

### `busyBlocks(date, opts)`

- `opts.typical === true` → พฤติกรรมเดิมเป๊ะ (ไม่ดูช่วงปิดเทอม ไม่ดูบันทึกรายวัน)
  ใช้กับ `ctxDayBar` (แท่ง "วันธรรมดาของคุณ" ในจอตั้งค่า) และ `ctxLearn` ซึ่งถามถึงสัปดาห์ปกติ ไม่ใช่วันจริง
- ไม่ใช่ typical:
  1. ถ้า `day.away` → คืนก้อนเดียว ตื่น→นอน ชื่อ "ไม่อยู่ทั้งวัน" (kind `'day'`)
  2. ถ้า `!ctxSchoolOn(date)` → ตัดคาบเรียน (`class`) และกิจวัตร kind `'travel'` ออก
  3. เพิ่ม `day.blocks` เป็น kind `'day'` (ชื่อจากที่จด)
- ข้อจำกัดที่รู้แล้ว: กิจวัตรที่ผูกกับโรงเรียนแต่ไม่ใช่ `travel` (เช่น ซ้อมกีฬาที่โรงเรียน) ยังอยู่ช่วงปิดเทอม
  ผู้ใช้ลบเองได้ หรือบอกผ่านบริบทรายวัน · ไม่ทำธงต่อกิจวัตรในรอบนี้

## AI: ฟังก์ชัน `read-day` (Supabase Edge Function ใหม่)

โครงเดียวกับ `read-timetable`: `geminiGenerate` + `responseSchema` + `verify_jwt = true` + กรองผลซ้ำก่อนคืน

**รับ** `POST { text, today: 'YYYY-MM-DD', now: 'HH:MM', summary }`
- `summary` = ข้อความสั้นที่แอปสร้างเอง: วันนี้มีเรียนกี่โมง/ปิดเทอมอยู่ไหม · ช่วงว่างที่เหลือ · งานค้าง 5 อันดับแรกของแผน (ชื่อ · ส่งเมื่อ · ประเมินกี่นาที) · งานแรกของแผนตอนนี้
- `text` ≤ 300 ตัว · `summary` ≤ 2,000 ตัว

**คืน** `{ ok: true, date, school, away, blocks, breakUntil, advice, note }`
- `date` วันที่ข้อความพูดถึง (วันนี้/พรุ่งนี้/วันเสาร์นี้) · ต้องอยู่ในช่วงวันนี้ถึง +7 วัน ไม่งั้นใช้วันนี้
- `breakUntil` วันเปิดเทอมถ้าข้อความพูดถึง ("ปิดเทอมถึง 2 พ.ย.") ไม่งั้น null
- `blocks` เวลา HH:MM ถูกรูปแบบ · end > start · สูงสุด 6 ก้อน · title ≤ 30 ตัว
- `advice` ≤ 160 ตัว ภาษาไทย · พูดเรื่องเวลาที่เหลือกับงานที่เสี่ยง · **ห้ามเสนองานแรกที่ต่างจากแผน** (สั่งในพรอมต์ + summary บอกงานแรกไว้แล้ว)
- อ่านไม่ออก → `blocks: []` และ `note` บอกเหตุผล · ห้ามเดาเวลาเอง

**ส่วนที่ทดสอบได้ด้วย node ตรง ๆ**: ตัวกรองผล (`clean.ts`) แยกเป็นไฟล์ไม่มี import ภายนอก
→ `node --test supabase/functions/read-day/__tests__/clean.test.mjs` (Node 24 ตัด type ของ .ts ได้เอง)

**deploy** ต้องให้เจ้าของสั่งก่อน — ก่อน deploy ฝั่งแอปต้องทำงานได้โดยไม่มีฟังก์ชันนี้ (ตกไปทางเลือกเวลาเอง)

## หน้าจอ

### 1) บรรทัด "วันนี้" บนหน้าแรก — แบบ ก "เดาให้ แล้วแตะแก้" (เจ้าของเลือก 18 ต.ค. 69)

*(แทนแบบแถวชิปถามทุกเช้า หลังเจ้าของให้ดูหน้าแรกของแอปเรียกรถ: เดาที่หมายจากประวัติ แตะแก้เมื่อผิด
ม็อกอัปสามแบบที่ใช้ตัดสินอยู่ที่ `alt/docs/superpowers/mockups/`)*

- บรรทัดเดียวทุกสถานะ (สูง 37px) `ไอคอน · สิ่งที่แอปเข้าใจ · ที่มา · เปลี่ยน` — แตะทั้งบรรทัดเปิดแผ่นข้อ 2
- คำเดามาจาก `ctxDayGuess(date)` ใน context.js:

| kind | เมื่อไหร่ | บรรทัด | แผนเชื่อไหม |
|---|---|---|---|
| set | ผู้ใช้จดแล้ว | ตามที่จด เช่น `ไปห้าง 16:00–18:00 · ไม่ไปเรียน` | เชื่อ |
| break | อยู่ในช่วงปิดเทอม | `ปิดเทอม · ไม่มีเรียน · เปิดเทอม 2 พ.ย.` | เชื่อ |
| carry | วันเรียนก่อนหน้า (ย้อน ≤ 3 วัน) จดว่าไม่ไปโรงเรียน และไม่ใช่ "ไม่อยู่ทั้งวัน" | `อยู่บ้าน · เหมือนเมื่อวาน` | เชื่อ (ไม่ไปโรงเรียน) |
| class | มีคาบตามตาราง | `ไปเรียน · ตามตาราง 08:00–15:30` | ตามตาราง |
| free | วันนี้ไม่มีคาบ | `วันนี้ไม่มีเรียน` | — |
| unknown | ยังไม่มีตารางเรียนเลย | `วันนี้ไปไหน · บอกแอปได้` | — |

- เดาจากคำตอบจริงเท่านั้น ไม่เดาซ้อนเดา · ไม่เดาช่วงเวลา · คำเดาไม่ถูกเขียนลงที่เก็บ
- บริบทของน้องไซบอกว่าเป็นคำเดาที่ผู้ใช้ยังไม่ยืนยัน
- วัดที่ 375×812 (alt) แล้วพอดีจอ · บิลด์รากล้นอยู่แล้ว 223px ก่อนเพิ่มบรรทัดนี้

### 2) แผ่น "วันนี้ไปไหน"

- ช่องพิมพ์ + ปุ่ม `ให้น้องไซอ่าน` → เรียก `read-day` → การ์ดยืนยัน "น้องไซจดแบบนี้ ถูกไหม":
  รายการช่วงเวลา · ข้อสังเกต AI · บรรทัด "งานแรกตอนนี้จะเป็น: X" ที่คำนวณจากแผนในเครื่อง **หลังลองใส่ช่วงใหม่** (ยังไม่บันทึก)
  ปุ่ม `ใช่ จดเลย` · `แก้เอง`
- แผ่นมีชิป `ไปโรงเรียน` · `อยู่บ้าน` ด้วยเสมอ — ช่วงปิดเทอมที่โรงเรียนเรียกไปซ่อมเสริมก็กด `ไปโรงเรียน` ได้จากที่นี่
- `แก้เอง` / ไม่มีเน็ต / ไม่ได้ล็อกอิน / AI ล้ม → ฟอร์มเลือกเวลาเอง: ช่วง (เริ่ม–จบ–ชื่อ) เพิ่มได้หลายช่วง + สวิตช์ `วันนี้ไม่ไปโรงเรียน` + `ไม่อยู่ทั้งวัน`
- ปุ่ม `กลับเป็นปกติ` (ลบบันทึกของวัน)
- ถ้า AI คืน `breakUntil` → การ์ดยืนยันมีบรรทัด "ตั้งปิดเทอมถึง … ด้วย" (ติ๊กไว้ให้ ถอดได้)

### 3) แชทน้องไซ + ช่องถามบนหน้าแรก

- ตัวคัดกรองในเครื่อง `aiDayOffer(text)` ก่อนส่งถามจริง (แบบเดียวกับ `aiTaskOffer`):
  มีคำบอกวัน (วันนี้ · พรุ่งนี้ · มะรืน · เสาร์/อาทิตย์นี้ · ปิดเทอม · เปิดเทอม · ไม่ไปโรงเรียน) **และ** คำบอกการไป/ธุระ หรือเวลา
  และไม่ลงท้ายเป็นคำถาม → เรียก `read-day` แล้วโชว์การ์ดยืนยันในแชท (role `'dayoffer'`) แทนการถาม
  การ์ดมีปุ่ม `จดเลย` · `ไม่ใช่ ถามต่อ` (ส่งเป็นคำถามปกติ)
- ด่านลำดับ: `aiTaskOffer` ก่อน แล้ว `aiDayOffer` — ข้อความเดียวไม่ขึ้นสองการ์ด

### 4) ปิดเทอม

- จอตารางเรียน (`renderContext`) เพิ่มแถว "ปิดเทอม": ยังไม่ตั้ง → ปุ่ม `ตั้งวันเปิดเทอม` (ช่องวันที่) · ตั้งแล้ว → `ปิดเทอม · เปิด 2 พ.ย. · ยกเลิก`
- แอปถามเอง: วันนี้ตอบ `อยู่บ้าน` และวันเรียนก่อนหน้า (วันที่มีคาบตามตาราง) ก็ตอบ `อยู่บ้าน` ด้วย และยังไม่มีปิดเทอมที่ครอบวันนี้
  → การ์ดบนหน้าแรกแทนแถบ: "ปิดเทอมแล้วใช่ไหม" + ช่องวันเปิดเทอม + `ใช่ ปิดเทอม` · `ไม่ใช่`
  กด `ไม่ใช่` → ไม่ถามซ้ำ 7 วัน (เก็บใน `localStorage` คีย์ใหม่ `studentos.alt.breakAskOff`)
- ถึงวันเปิดเทอม ตารางกลับมาเอง (เพราะ `ctxBreakOn` เป็น null)

### 5) บริบทที่ส่งให้ AI (`aiContext`)

- เพิ่มหัวข้อ `## บริบทวันนี้`: ไปโรงเรียนไหม · ช่วงที่ไม่อยู่ · ข้อความที่จด · ปิดเทอมถึงวันไหน
- ช่วงปิดเทอม หัวข้อตารางเรียนเขียนว่า "ปิดเทอมถึง … ช่วงนี้ไม่มีคาบเรียน" แทนการลิสต์คาบ
- เวลาว่างที่เหลือวันนี้คิดผ่าน `busyBlocks` ใหม่อยู่แล้ว
