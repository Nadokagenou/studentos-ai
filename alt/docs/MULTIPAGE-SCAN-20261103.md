# ALT: หัวข้อหลัก รายละเอียด และหลายรูปต่อหนึ่งงาน · 3 พฤศจิกายน 2569

ผู้ใช้ต้องการให้ช่องชื่องานเหลือหัวข้อหลัก เนื้อหาที่เหลือเป็นรายละเอียด และยืนยันให้อ่านทุกรูปรวมเป็นงานเดียวพร้อมเก็บรูปทั้งหมด ต่อมาสั่งให้ขึ้น ALT ให้ดูก่อน ชุดเผยแพร่นี้มีเฉพาะ frontend สำหรับอ่านในเครื่อง ไม่รวมไฟล์บริการ Supabase และไม่เปลี่ยนเว็บหลัก

## พฤติกรรม

- เลือกรูปจากคลังได้หลายใบ หรือถ่ายต่อทีละใบ ครอปแต่ละหน้าแล้วเก็บในคิวเดียว สูงสุด 6 รูป เรียง/นำรูปออกก่อนอ่านได้
- กดอ่านรวมเมื่อเพิ่มรูปครบ อ่านทีละหน้าด้วยท่อเตรียมภาพ/OCR เดิม ไม่แยกเป็นหลายงานและไม่อ่านหลายหน้าแข่งกันใน worker เดียว
- ชื่อหลักสั้นไม่เกิน 60 ตัวอักษร เลขข้อ วิธีทำ รูปแบบไฟล์ ช่องทางส่ง และคำสั่งจากหน้าถัดไปไปอยู่ใน note ถ้ารายละเอียดยาวเกินช่อง ระบบบล็อกให้แก้ก่อน ไม่ตัดทิ้งเงียบ ๆ
- เก็บรูปทุกหน้ากับงานในคลังเดิมเมื่อกดบันทึกเท่านั้น รูปเป็น localOnly ไม่มีการเริ่มอัปโหลด ยกเลิกการครอปใหม่หรือบันทึกงานอื่นไม่ล้างคิวรูปเดิม
- หน้าใดอ่านไม่ออกจะไม่สร้างงานจากผลบางส่วน เก็บรูปทั้งชุดให้ผู้ใช้ถ่ายใหม่หรือนำหน้าที่ไม่ต้องการออก

## กติกา AI ที่เตรียมไว้

มีร่าง prompt และสัญญา `ocr-assist` ในเครื่อง พร้อมตัวอย่าง title/detail แยกกันและอ่านภาพทุกหน้าตามลำดับ รับภาพ 1–6 ใบภายในคำขอเดียว จำกัดขนาดรวมตาม MAX_BYTES เดิม และแจ้ง unreadablePages ชัดเจน ร่างนี้ไม่อยู่ในชุดเผยแพร่และยังไม่ได้ deploy

ใช้เฉพาะคำขอ ALT ที่ส่ง `taskFormat: 'title-note-v2'` ลูกข่าย main/รุ่นเดิมที่ไม่ opt-in ยังใช้ prompt เดิม แอปตรวจ imageCount ก่อนยอมรับผลหลายหน้า เพื่อกันบริการเก่าอ่านเพียงรูปแรก

ผู้ใช้แจ้งว่า Supabase ระงับจากเกินโควตาและคาดว่าจะกลับมาประมาณ 19 พ.ย. ข้อจำกัดยังไม่ถูกยกเลิก ชุดทดสอบไม่เรียก Supabase/โมเดลจริง ไม่แก้ล็อกอิน ซิงก์ หรือ Halloween และไม่ deploy บริการ การกดอ่านชุดรูปใช้ OCR ในเครื่อง; การกด cloud retry แจ้งว่าบริการหยุดแทนการลองยิงซ้ำ
