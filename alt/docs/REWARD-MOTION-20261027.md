# เปิดฉากรางวัลได้โดยไม่ต้องมีธีม Halloween · 27 ตุลาคม 2569

ผู้ใช้ได้รับเอฟเฟกต์แล้วแต่เล่นไม่ได้ เพราะเครื่องขอลดการเคลื่อนไหว ข้อความเดิมไม่มีทางแก้ในหน้าเดียวกัน และสวิตช์ธีม Halloween ต้องมีธีมก่อน

## พฤติกรรมใหม่

- ฉัน → ธีมสี → เอฟเฟกต์ตอนงานเสร็จ มี “การเคลื่อนไหวฉากรางวัล” อยู่ติดปุ่มดูตัวอย่าง เมื่อเลือก Cursed Ship หรือหนึ่งในแปดฉากรางวัล ไม่ต้องเลือกหรือเป็นเจ้าของธีม Halloween
- “ตามการตั้งค่าเครื่อง” เป็นค่าเริ่มต้นและยังเคารพ reduced motion/ภาพนิ่งธีม/กราฟิกน้อย เลือก “เปิดฉากรางวัล” เองแล้วเปิดเฉพาะฉากนี้ รวมถึงตอนทำงานเสร็จจริง เลือก “ภาพนิ่ง” หรือกลับตามเครื่องได้
- ถ้ากดดูตัวอย่างขณะถูกปิด มีปุ่ม “เปิดฉากรางวัล” ในข้อความแจ้ง กดแล้วบันทึกตัวเลือกและเล่นต่อโดยตรง ไม่มีการเปิดเองก่อนกด
- ตัวเลือกใหม่ต่อเครื่อง `studentos.alt.cinematicMotion` ไม่เปลี่ยนคีย์งาน/คลัง/ธีมเดิม ไม่แก้ matchMedia, กราฟิก, เพลง หรือการตั้งค่า OS และไม่แจกสิทธิ์รางวัลหรือเปิดอีเวนต์ก่อนเวลา
- เฉพาะหน้า viewer การกดเล่นอนุญาตเคลื่อนไหวสำหรับตัวอย่างนั้นได้ โดยไม่แทน window.matchMedia ทั่วหน้าอีกแล้ว
- ทรัพยากรยังต้องโหลดพร้อม และข้ามฉากได้ตลอด ทุกฉากยังใช้เวลา6วินาที งานถูกบันทึกก่อนเล่นเช่นเดิม

## การตรวจ

- เห็นเทสต์ใหม่4กรณีล้มเพราะยังไม่มี policy/control/CSS opt-in ก่อนเพิ่มโค้ด
- Halloween+economy288/288 ผ่าน: เปิดเฉพาะฉากโดยไม่แก้ OS/theme/quality, อ่านตัวเลือกที่บันทึก, หน่วยความจำเมื่อ storage ใช้ไม่ได้, gate ตอนจบงานจริง, ปุ่ม enable ตรงข้อความแจ้ง และ CSS scope
- ALT service worker6/6 ผ่านและ syntax hoop.js/cursed-ship.js ผ่าน คง APP_VERSION1C60 เปลี่ยน cache เป็น1c60-reward-motion-20261027
- Browser: ธีมมืดธรรมดา แสดงตัวเลือกตามเครื่องแล้วเป็นภาพนิ่ง กดดูตัวอย่าง → เปิดฉากรางวัล แล้ว The Cursed Ship เล่นจริง เลือกรอยคลื่นวิญญาณเล่นได้ csSeal/running, data-theme=dark และ data-cs-motion=full
- ห้องลองใช้ memory storage จึงตั้งใจไม่จำค่าหลัง reload ของห้องลอง การจำค่าจริงตรวจด้วย storage fixture โดยไม่แก้บัญชีจริง
- รวมงานทีมถึง079526e ก่อนแก้ ไม่เปลี่ยนภาพจันทร์หยก เพลง หรือโค้ดapp.jsของทีม

- UI320×568และ375×812 ไม่มีล้นข้าง ช่องเลือกสูง44px บนจอ320ช่องกว้าง218px ข้อความอยู่ในกรอบ
- Browserฉาก8/8จบ6055–6099ms callbackครั้งเดียว โหนดค้าง0 scene fixtureไม่มีerror/warning
- app fixtureเล่นและตั้งค่าได้จริง แต่พบconsole MutationObserver.observe หนึ่งรายการโดยไม่มีsourceตำแหน่ง ไม่อ้างว่าconsoleทั้งแอปสะอาด ไฟล์รอบนี้ไม่ได้เพิ่มMutationObserver
