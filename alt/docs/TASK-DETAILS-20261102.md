# รายละเอียดและรูปแนบในฟอร์มงาน ALT · 2 พฤศจิกายน 2569

ตามคำสั่งเจ้าของให้ขึ้น ALT ก่อน เพิ่มช่องรายละเอียดและรูปโจทย์ในฟอร์มเพิ่ม/แก้ไขงาน และเปิดอ่านได้ระหว่างโฟกัส รูปที่ส่งเข้าอ่านหลังครอปแนบเข้าผลสแกนใบนั้นอัตโนมัติ เก็บเมื่อยืนยันบันทึกงานเท่านั้น ยกเลิกหรือเปิดงานอื่นจะไม่ยืมรูปสแกนเก่า

ฐานคือ ALT ที่มีคลังงานแล้ว (`3ac68ed`) ใช้ `t.note`, `t.files` และ IndexedDB `studentos-files` เดิม ไม่สร้างคลังซ้ำ รายละเอียดใช้เส้นทางบันทึกงานเดิม รูปใหม่ผ่านฟอร์มนี้เป็น JPEG ไม่เกิน 1 MB ด้านยาวไม่เกิน 1,600 px และระบุ `localOnly` ทั้ง metadata และ blob; uploader ข้ามรูปเหล่านี้ ไม่เพิ่ม polling หรือเรียกซิงก์/อัปโหลดจากฟอร์ม ฟอร์มแสดงรูปโจทย์ในเครื่องได้ 6 รูป รูปอื่นและรูปที่ยังไม่มีในเครื่องคงอยู่ในคลังและไม่ดาวน์โหลดมาเปิดฟอร์ม

รูปเฉพาะเครื่องยังไม่ตามไปเครื่องอื่น การล้างข้อมูลเว็บไซต์ทำให้รูปหาย ดาวน์โหลดรูปสำคัญจากหน้าดูรูปไว้ได้ ตัวระบบคลังงานที่ทีมเพิ่มไว้ก่อนหน้านี้ยังมีทางอัปโหลดของตนเอง ไม่ได้เปิด migration หรือเปลี่ยนบริการในงานนี้

คงรุ่น 1C60 และคีย์ข้อมูลเดิม แคช ALT `studentos-alt-1c60-task-details-20261102` รวมไฟล์ใหม่ทั้งสาม ไฟล์เว็บหลักที่รากไม่เปลี่ยน
