# Halloween preview · Midnight Academy

22 ตุลาคม 2026 · ตัวอย่างธีมสำหรับ ALT · เลขแอปยังเป็น 1C60

## เปิดลอง

รัน `node alt/devtools/desktop-preview.mjs --port=4199` จากโฟลเดอร์โครงการ แล้วเปิด `http://127.0.0.1:4199/alt/device-preview.html`

เซิร์ฟเวอร์นี้ใช้ข้อมูลจำลองและปิดการเชื่อมบัญชีจริง หน้าแอปปกติคือ `/alt/` และเลือก Halloween จาก ฉัน → ธีมสี ได้

## เครื่องมือตรวจหน้าจอ ALT

ปุ่ม “ตรวจหน้าจอ” และลิงก์ในตั้งค่าธีมเป็นเครื่องมือของ ALT ใช้กับทุกธีม แยกจากอีเวนต์ Halloween:

- มือถือ 375 × 812
- แท็บเล็ต 820 × 1180
- คอม 1440 × 900

iframe ใช้ความกว้างและความสูงตามตัวเลขจริง แล้วจึงย่อภาพให้พอดีพื้นที่ ไม่ล้างข้อมูลหรือรีโหลดแอปเมื่อเปลี่ยนอุปกรณ์

ไฟล์เครื่องมือ: `device-preview.html`, `device-preview.css`, `device-preview.js`, `device-preview-bridge.js`, `device-preview-controls.css`

## ธีม

- ฉากโรงเรียนยามค่ำ พระจันทร์ ค้างคาว หมอก แสงเทียน และประกายวิญญาณ
- สุสานด้านล่าง หลุมศพ รั้ว ฟักทอง หญ้าแห้ง และผีสองตัวเดินผ่านคนละทิศ
- การ์ดงานและปุ่มหลักมีควันเทา รอยเลือดตามขอบ และผีจาง ๆ โดยไม่รับคลิกทับเนื้อหา
- ขยายลวดลายไปยังราง “ที่เหลือของวันนี้”, เมนูเพิ่มงาน, การ์ดภาพรวมวันนี้ และปุ่มทั้งหมดในหน้า “ฉัน” รวมตัวเลือกห้อง/เหรียญ/ธีม เช็คอิน กราฟ และรายการฟีเจอร์
- หน้างานครบทั้งวันนี้/สัปดาห์/รายการ: ตกแต่งแท็บ ปุ่มเริ่มทำ ปุ่มถ่ายตารางเรียน แถวงาน ตัวกรอง/ค้นหา ปุ่มทำเสร็จ ปุ่มงานย้อนหลังและปุ่มย้อนกลับ พร้อมกรอบสัปดาห์และการ์ดงาน ปุ่มทำเสร็จยังใช้สีเขียวและปุ่มลบใช้สีแดง
- ป้ายระยะเวลาบนการ์ดงานใช้ตัวอักษรม่วงเข้มบนพื้นลาเวนเดอร์ วัดอัตราส่วนคอนทราสต์ได้ 9.01:1
- เปลี่ยนการ์ด ช่องพิมพ์ แถบนำทาง ไอคอน มาสคอต และหน้าต่างต่าง ๆ
- เพลงต้นฉบับ Midnight Waltz แบบกล่องดนตรี 8 ห้อง จังหวะวอลซ์ A minor มีทำนอง เบสและคอร์ด พร้อมเสียงลมเบา เสียงแตะ เปลี่ยนหน้า และงานเสร็จ สังเคราะห์ในเครื่องด้วย Web Audio เปิดเองได้ ปรับระดับเสียงรวมและปิดเฉพาะเพลงได้ หยุดเมื่อออกจากธีมหรือซ่อนหน้า
- น้องไซแม่มดและน้องฮูกมัมมี่ใช้ WebP รวมประมาณ 350 KB รวมโลโก้ เก็บต้นฉบับไว้ในโฟลเดอร์ Halloween กลาง
- เคารพการลดการเคลื่อนไหวของระบบเป็นค่าเริ่มต้น ผู้ใช้เลือกเปิดภาพเคลื่อนไหวเองได้ โหมดกราฟิกกลางหยุดภาพ โหมดต่ำซ่อนฉาก

ไฟล์ธีม: `halloween.css`, `halloween.js`, `halloween-assets/`; โทเคนและทะเบียนธีมอยู่ใน `alt.css`, `app.js`, `index.html`

## ขอบเขตและความเข้ากันได้

ใช้หน้าหลักและรูปแบบฟอร์มจากเวอร์ชันหลัก โดยรักษาส่วนแก้บั๊กเดิมของ ALT: parser, เวลานัดทำงาน, การซิงก์/สลับบัญชี, การกู้ผลสุ่ม, ความเป็นส่วนตัว และการลดกราฟิกไว้ Root runtime และ `style.css` ไม่ถูกแก้ ไม่มีการเปลี่ยนคีย์ข้อมูลเดิมหรือเลขรุ่น

ยังเป็นตัวอย่างหน้าตา ไม่เชื่อมการปลดล็อกรางวัล Candy บ้าน NPC หม้อแม่มด หรือพิธี เปิดเลือกจาก ฉัน → ตั้งค่า → ธีมสี → Halloween ได้ ส่วนเครื่องมือตรวจจออยู่ที่ `/alt/device-preview.html`

## ผลตรวจ

- หน้าแรกทั้งสามขนาด: ไม่มีส่วนเกินแนวนอน และความสูงเนื้อหาไม่เกินพื้นที่หน้าแรกที่ขนาดทดสอบ
- สลับธีมสว่าง/Halloween แล้วกลับได้ ภาพเดิมคืน เสียงหยุด และปุ่มตรวจหน้าจอยังอยู่
- เปิดเสียงในแอปได้ AudioContext อยู่ในสถานะ running; ปุ่มหยุดภาพทำให้ animation ของผีและควันเป็น none
- เปิดงาน ฉัน ร้านค้า ห้อง และตั้งค่าบนคอมได้โดยไม่มีส่วนเกินแนวนอน
- Parser 106/106; กู้ผลสุ่ม 10/10; AI plan context 4/4; บัญชี 33/33; ซิงก์ 36/36; push 12/12; บริบทรายวัน 29/29; กล่องเข้า 18/18; service worker 5/5; ทางลัดคอม 7/7; shortcuts 10/10
- ตรวจฉากรวม Halloween 161 กฎ: แอนิเมชันฉากใช้ transform/opacity และไม่มีแอนิเมชันแย่ง transform กัน
- ตรวจหน้างาน 3 โหมด × 3 ขนาดจอ ไม่มีส่วนเกินแนวนอน เปิดงานที่เสร็จแล้วและย้อนกลับได้ ลวดลายบนปุ่มซ่อนเมื่อสลับเป็นธีมสว่าง
- แก้เมนู “เพิ่มอะไร?” ลอยติดด้านบน: ไม่ให้กฎตกแต่งทับ position ของคอมโพเนนต์ ใช้ `.hw-art-host` ที่มี specificity เป็นศูนย์สำหรับองค์ประกอบที่ยังไม่ได้กำหนดตำแหน่งเท่านั้น ตรวจเมนูชิดขอบล่างที่ 375×812 และ 820×1180; คอม 1440×900 อยู่กึ่งกลางกว้าง 600px ห่างขอบล่าง 24px ตามผังเดิม ปุ่มติ๊กงานคง absolute/top/right เดิม
- รวมอัปเดต `origin/main` ถึง 2066638 โดยไม่มีการเปลี่ยน root runtime ตรวจซ้ำ 6 หน้า × 3 ขนาด และหน้างาน 3 โหมด × 3 ขนาด ไม่มีส่วนเกินแนวนอน
- หน้าแรกกรณีไม่มีงานและเลยเวลางาน: 375×812, 820×1180, 1440×900 ไม่ต้องเลื่อน ไม่มีข้อผิดพลาดที่บันทึกจากหน้า QA
- เพิ่มงานจำลองผ่านฟอร์มสองขั้น เลือกวิชาและวันส่งได้ งานปรากฏในแผน; เปิดแผ่นงานในเส้นเวลา เริ่ม/หยุดจับเวลาและทำเสร็จได้ แผ่นงานบนมือถือกว้าง 375px ชิดขอบล่าง
- แก้สีตัวอักษรแถบจับเวลาเป็นเขียวเข้มบนพื้นเขียวอ่อน รักษาปุ่มกราฟิก 3 ระดับและค่าก่อนวาดหน้าแรก รวมถึง compat สำหรับเบราว์เซอร์เก่า เส้นทางห้องเรียน ตัวกันปิดเมนูค้าง การซ่อนแผงเหตุผลจากคีย์บอร์ด และการจำตำแหน่งแชทเดิม
- ซ่อมตัวตรวจ syncbench ให้รอคิวซิงก์จริงหลัง debounce และคืน exit code ผิดพลาดเมื่อมี assertion ไม่ผ่าน ผ่าน 36/36 หลังแก้ตัวตรวจ ไม่มีการเปลี่ยนระบบซิงก์จริง
- เปลี่ยนเฉพาะชื่อแคชทรัพยากรเป็น `studentos-alt-1c60-halloween-music-20261022` เพื่ออัปเดตไฟล์ธีม เลขแอปคงเดิม
- ทางลัดเพิ่มงานด่วนและร่างคำถามใช้รูปแบบเดียวกับหน้าหลัก เก็บข้อความที่ยังไม่ส่งไว้ ส่งไม่สำเร็จยังแก้แล้วลองใหม่ได้ และคงการแสดงนัดเตือน `doAt` ของ ALT
- ตรวจทางลัด ALT 9/9: ข้อความเป็นร่างที่ยังไม่ส่ง ไม่ทับสิ่งที่พิมพ์เอง จำกัดความยาว/อายุร่าง และไปต่อหลังล็อกอินได้ ชุดตรวจอยู่ใน `devtools/shortcuts.test.mjs`
- รอบปรับสีหน้าธีม/การ์ดเคลียร์งานและเพิ่มเพลง: ตรวจวงจรเสียงจำลอง 7/7 (`devtools/halloween-audio.test.mjs`) ครอบคลุมการยินยอมเปิดเสียง ไม่เล่นซ้อน ปิดเพลงแยก การล้างโน้ตและตัวจับเวลา และข้ามช่วงที่ตัวจับเวลาหน่วง รอบเพิ่มเพลงนี้ยังไม่ได้ยืนยันภาพหรือฟังจากเบราว์เซอร์จริง

ยังไม่ได้วัด FPS บนเครื่องจริงหรือทดสอบการใช้งาน cloud จริง พรีวิวขนาดจอใช้สำหรับตรวจผัง ไม่ได้จำลองคีย์บอร์ดสัมผัสหรือฮาร์ดแวร์ทุกอุปกรณ์
