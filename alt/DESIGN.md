## 1. หลักการ

1. **หนึ่งจอ หนึ่งการกระทำหลัก** — ปุ่มทึบสีเน้นมีได้ปุ่มเดียวต่อจอ (การ์ด "ตอนนี้" → "เริ่มทำเลย")
2. **ทอง = สำเร็จแล้วจริงเท่านั้น** — ห้ามใช้ทองกับของที่ยังไม่ได้ทำ (ดู AGENTS.md)
3. **กระจก (Liquid Glass 1C40) ใช้กับตัวควบคุมเท่านั้น** — ปุ่ม แถบล่าง ช่องพิมพ์ · ไม่ใช่การ์ดเนื้อหา
4. **หน้าแรก (`scr-menu`) ไม่ต้องเลื่อนที่ 375×812** — วัดทุกครั้งที่เพิ่มบล็อก
5. **ห้ามสีดิบในกฎของจอ** — ใช้โทเคนของธีมเสมอ ไม่งั้นสวยธีมเดียวแล้วพังอีก 14 ธีม

## 2. สี (มีครบแล้ว — ใช้ตามบทบาท ไม่ใช่ตามเฉด)

| โทเคน | บทบาท | เกณฑ์ contrast |
|---|---|---|
| `--scr` | พื้นจอ | — |
| `--card` · `--card2` | การ์ด · พื้นรอง/ช่องกรอก | — |
| `--ink` | ตัวหนังสือหลัก | ≥ 7:1 บน `--card` |
| `--muted` | ตัวหนังสือรอง | ≥ 4.5:1 บน `--card` และ `--scr` |
| `--faint` | ป้ายจาง (เวลา · หมายเหตุ) | ≥ 4.5:1 บน `--card` · **ไม่วางบนพื้นที่ขยับได้** |
| `--blue` / `--on-accent` | สีเน้น / ตัวหนังสือบนสีเน้น | ≥ 4.5:1 |
| `--fill` / `--on-fill` | พื้นทึบของปุ่มหลัก · แท็บที่เลือก · ไทล์ | ≥ 4.5:1 |
| `--alert` `--warn` `--good` (+`-soft`) | สถานะ | ตัวหนังสือ ≥ 4.5:1 บน `-soft` |
| `--pri-red/yellow/green` (+`-text`) | ระดับความด่วน — คงที่ทุกธีม | — |
| `--gold` `--grad-gold` `--on-gold` | ของที่สำเร็จแล้ว (Astral = เงิน) | ≥ 4.5:1 |

ไอคอนที่เป็นปุ่ม (เช่นปุ่มส่ง) ต้องได้ ≥ 3:1 กับพื้นข้างหลัง

**ปุ่มหลักใช้ `--fill`/`--on-fill` คู่เดียว** — `.btn.primary`, `.fm-save`, `.tc-cta`, `.sai-cta` ต้องหน้าตาเดียวกัน
(ตอนเขียนยังมีสองชุด: `--blue` กับ `--fill` · ในธีมมืดได้ฟ้าอ่อน+ตัวดำ กับ น้ำเงิน+ตัวขาว)

## 4. ระยะห่าง (ฐาน 4)

`--sp-1:4px` · `--sp-2:8px` · `--sp-3:12px` · `--sp-4:16px` · `--sp-5:24px` · `--sp-6:32px`

- ระยะระหว่างบล็อกบนหน้าแรก = `--sp-4` (16px)
- ขอบซ้ายขวาของจอ = 16–20px
- ช่องไฟในการ์ด = `--sp-4`

## 6. ปุ่ม

| แบบ | หน้าตา | ความสูง |
|---|---|---|
| primary | ทึบ `--fill` · ตัว `--on-fill` · แคปซูลกระจก | 52 (md) / 44 (sm) |
| secondary | พื้น `--card` · เส้น `--line` · ตัว `--ink` | 52 / 44 |
| ghost | ไม่มีพื้น · ตัว `--blue` | 44 |
| icon | กล่องกระจก 42×42 (ปุ่มกลับ/ปิด ทุกจอ) | 42 |

- **เป้ากดขั้นต่ำ 44×44** — ไอคอนเล็กกว่านั้นได้ แต่ต้องขยายพื้นที่รับนิ้วด้วย `::before { inset:-10px }` (ดูท้าย `alt.css`)
- ปุ่มที่ใช้ไม่ได้: `disabled` → จาง .5 อัตโนมัติ (กฎกลางท้าย `alt.css`)
- ทุกปุ่มต้องเป็น `<button>` — `div onclick` ถูกติดป้าย role/tabindex ให้อัตโนมัติ (`tagClickables` ใน app.js) แต่เป็นตาข่ายรอง ไม่ใช่วิธีเขียน

## 7. ชั้นที่ทับจอ (แผ่น · modal)

- ลงทะเบียนใน `OVERLAYS` (app.js) **ที่เดียว** → ได้ Esc · ปุ่มย้อนของเครื่อง · วงโฟกัส · คืนโฟกัส ครบ
- คอนเทนเนอร์ใช้ `hidden` ปิดเปิด และใส่ id ลงใน `watchOverlays()` ด้วย
- การ์ดข้างในมี `role="dialog"` + `aria-label`
- ห้ามเด้งของที่ไม่เกี่ยวกับงานตรงหน้า (ของรางวัล · โปรโมต) ทับจอที่ไม่ใช่หน้าแรก

## 8. เพิ่มธีมใหม่ — checklist

1. `THEME_BAR` + `THEME_NAME` ใน app.js
2. ตาราง `BAR` ใน `<head>` ของ index.html
3. บล็อกโทเคนใน alt.css (ครบทุกตัวในข้อ 2)
4. ถ้าเป็นธีมมืด: เพิ่มชื่อธีมใน `:is([data-theme=dark],…)` ทุกรายการใน alt.css (แถบล่าง · ปุ่มส่ง · กระจก)
5. เช็ค contrast ตามตารางข้อ 2 — `--muted` และ `--faint` บน `--card` กับ `--scr`
