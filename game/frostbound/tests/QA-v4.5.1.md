# FROSTBOUND v4.5.1 · การแก้ภาษาไทย

ซอร์สตั้งต้นคือ `a4f80ea744e01bc764403f6fd827ba93b1d600a5` ของ PR #105 ผู้เล่นใหม่เปิดเกมเป็นภาษาไทยโดยไม่ขึ้นกับภาษาของเบราว์เซอร์ ปุ่ม **ไทย / English** อยู่มุมขวาบนของหน้าแรก ค่าที่บันทึกใน `frostbound.language.v1` ยังอ่านได้ และเมนูตั้งค่าสลับภาษาในรอบเดิมได้ทันที

## ผลการตรวจ

| การทดสอบ | ผล |
|---|---|
| Regression | 85/85 ผ่าน |
| Story ใน Chrome | ใช้สคริปต์กดผ่าน UI จริง เล่นครบห้าภูมิภาคด้วย seed 4212 จบที่คะแนน 6586 ผ่านบอสเฟส I–III และเห็นฉากชนะภาษาไทย |
| Hardcore | ตรวจเส้นทางอันตราย หน้าพ่ายแพ้ สถิติ โหมด No-Save และการเริ่มรอบใหม่ |
| Boss Rush | เลือกสกิลเปิดรอบ ใช้จริง เห็นข้อความพักสกิล และผ่านบอสสามตัว |
| การสลับภาษา | Chrome ที่ตั้งภาษาระบบเป็น en-US เปิดไทย สลับอังกฤษและไทยผ่านหน้าแรก ตรวจทั้งสองค่าหลังโหลดซ้ำ และสลับภาษาในหน้ารางวัลโดยคงการ์ดเดิม |
| DOM | ทดลองเขียนตัวอักษรอังกฤษทับ HUD ที่ผูกคีย์โดยตรง ระบบคืนข้อความไทยโดยไม่รอให้เกมวาดเฟรมใหม่ |
| จอและข้อความ | เดสก์ท็อปและจอสัมผัสจำลองห้าขนาด รวม 568×320 ทดสอบหมุนจอ 58 ครั้ง อ่านคำไทยและมองเห็นปุ่มภาษาในกรอบจอ |
| ระบบต่อสู้ | การควบคุมคีย์บอร์ด สัมผัส อาวุธหกชุด และ Perfect Parry ผ่าน ข้อมูลวัดสมดุลตรงกับ v4.5 |

## ข้อความที่ตรวจ

ตรวจ 65 จุดในหน้าแรก เลือกโหมด บทนำ ฝึกฝน HUD ห้องทั้งห้าภูมิภาค ป้ายชื่อการโจมตีบอสและข้อความ Canvas กระเป๋า คำอธิบายอาวุธ สกิล ร้านซื้อขาย รางวัล บทสนทนาและเหตุการณ์ หน้าผลรอบ สถิติ ตั้งค่า และคู่มือ ตัวตรวจจับทั้งคีย์ที่ขาดและข้อความอังกฤษทั่วไปในหน้าที่เปิดอยู่ รวมถึงป้ายสำหรับโปรแกรมอ่านหน้าจอ

ผลทั้งสองชุดเหลือ **0 ข้อความอังกฤษทั่วไป** และ **0 คีย์ที่ขาด** ในจุดที่ตรวจ ชื่อเกม ตัวละคร อาวุธ ภูมิภาค คำกำกับปุ่มและตัวย่อ เช่น FROSTBOUND, Eldric, Frost Edge, The Frozen King, Frost Crowns, HP และ WASD เป็นรายการที่ตั้งใจคงไว้ ปุ่ม English และศัพท์ฝั่งอังกฤษในหน้า Glossary เป็นข้อความสองภาษาโดยตั้งใจ [ผลตรวจระหว่างเล่น](visual/v451/audit-campaign.json) · [ผลตรวจหน้าจอและคู่มือ](visual/v451/audit-landscape.json)

การตรวจเหตุการณ์ครอบคลุมรายการในแค็ตตาล็อกและเส้นทางที่เล่นจริงในชุดทดสอบ การตรวจมือถือใช้ Chrome จำลองหน้าจอและสัมผัส

## ทดสอบซ้ำ

จากโฟลเดอร์เกม ใช้ Node 24 และ Chrome กับ Playwright สำหรับชุดเบราว์เซอร์

```text
node --test --test-isolation=none tests/*.cjs
node tests/browser/campaign.cjs . <output-dir> --thai
node tests/browser/campaign.cjs . <output-dir>
node tests/browser/landscape.cjs . <output-dir> --extended
node tests/browser/controls.cjs . <output-dir>
node tests/browser/faults.cjs .
node tests/stress/balance.cjs .
```
