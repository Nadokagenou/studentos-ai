- ตัวแนะนำการหมุนจอหยุดการจำลองชั่วคราวโดยคงเมนูที่เปิดไว้เดิม เมื่อกลับเป็นแนวนอน หากผู้เล่นพักเกมไว้ เกมจะรอให้กดเล่นต่อ

## ผลทดสอบ

- Regression v4.3 **77/77** และ v4.4 **81/81** ผ่าน ตรวจคลังคำแปลจากข้อมูลห้องหลาย seed, รายละเอียดอุปกรณ์และสกิล, ข้อความตามตัวเลข และการคงรอบกับเฟรมเดียวระหว่างหมุนจอ
- จำลองการเล่น 50 รอบ รวม **499 การเปลี่ยนห้อง** ผลสอดคล้องกับ v4.3 โดย Story ชนะ 20/20, Hardcore ชนะ 1/20 และ Boss Rush ชนะ 10/10
- Chrome เปิดเกมจาก URL ย่อย ทดสอบ 1440×900, 844×390, 740×360, 568×320, 390×844 และ 1024×768 ครอบคลุมจอยทแยงพร้อมปุ่มทั้งหก, ยกเลิกสัมผัส, เต็มจอเมื่อเบราว์เซอร์ปฏิเสธ, การหมุนจอขณะต่อสู้ พักเกม เลือกรางวัล เปิดกระเป๋า ซื้อของ สนทนา เปลี่ยนเฟสบอส และดูหน้าผลการเล่น
- การเดินเกมอัตโนมัติใน Chrome เริ่ม Story ภาษาไทย สลับเป็นอังกฤษหลังการต่อสู้ครั้งแรก ผ่านร้านค้า ห้องพัก ห้องลับ และ Frozen King เฟส 2–3 ส่วน Hardcore ทดสอบเส้นทาง Danger, Records และ No-Save และ Boss Rush ผ่านครบสามบอส
- ทดสอบการเคลื่อนที่ด้วยคีย์บอร์ด อาวุธเบา/หนักครบหกตระกูล และ Perfect Parry โดยใช้ปุ่มของเกมจริงใน Chrome

## ประสิทธิภาพ

วัดใน Chrome เครื่องเดียวกัน ใช้ seed 4212 และห้อง Hollowpine Forest จอแนวนอนอิง iPhone preset ค่าหน่วง input วัดตั้งแต่เหตุการณ์คีย์หรือสัมผัสถึงเฟรมที่เกมรับท่าโจมตี

| สภาพทดสอบ | FPS ก่อน → หลัง | p95 / p99 เฟรม (ms) | JS วาด p95 (ms) | Heap หลัง GC (MiB) |
|---|---:|---:|---:|---:|
| เดสก์ท็อป High | 56.44 → 56.70 | 18.1 / 18.2 → 18.1 / 18.1 | 0.3 → 0.3 | 2.95 → 3.17 |
| มือถือจำลอง High | 56.67 → 56.73 | 18.1 / 18.2 → 18.2 / 18.3 | 0.3 → 0.4 | 2.94 → 3.16 |
| มือถือจำลอง Low | 28.31 → 28.35 | 36.0 / 36.2 → 36.0 / 36.2 | 0.3 → 0.3 | 2.98 → 3.20 |

เดสก์ท็อป Low มีเฟรมช้าประปรายในการวัดครั้งแรกทั้งสองรุ่น รอบวัดแยกพบอีกครั้งใน v4.3 จึงเก็บข้อมูลไว้และใช้คู่ผล High กับมือถือ Low เทียบแนวโน้ม ค่า median ของ input คีย์บอร์ด 9.0 → 12.9 ms และจอสัมผัส 16.2 → 16.2 ms จากตัวอย่างที่เกมรับท่า 6–8 ครั้งต่อชุด

การหมุนจอ 20 ครั้งมีเวลา p95 จากคำสั่ง Chrome ถึงสถานะ UI ที่คาดไว้ 64.4 ms หลังหมุนซ้ำ 12 รอบ heap หลัง GC เปลี่ยน 2.40 → 2.63 MiB ข้อมูลดิบอยู่ใน [v4.3](visual/v44/performance-before.json), [v4.4](visual/v44/performance-after.json) และ [การหมุนจอ](visual/v44/rotation.json)

## รันซ้ำและตรวจรีลีส

รันจาก `game/frostbound` บน Node.js 24 Chrome suites ใช้ Playwright และรองรับ `FROST_CHROME` เพื่อระบุตำแหน่ง Chrome เครื่องที่ทดสอบ

```powershell
node --test --test-isolation=none tests/*.cjs
node --expose-gc tests/stress/run.cjs
node tests/browser/landscape.cjs . qa/landscape
node tests/browser/campaign.cjs . qa/campaign
node tests/browser/controls.cjs . qa/controls
node tests/browser/visual.cjs . qa/profile --landscape
```

ก่อน Team Beta ให้ทีมตรวจสำนวนและการอ่านคำบรรยายระหว่างต่อสู้ ทดสอบ Safari/iPhone และ Android จริงเพื่อยืนยันพื้นที่รอยบาก การจับหลายจุด และปุ่มเต็มจอ จากนั้นจึงอนุมัติ commit สำหรับเว็บไซต์หลัก
