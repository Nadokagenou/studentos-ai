## ข้อบกพร่องที่แก้แล้ว

| ระดับ | อาการใน v4.4 | ผลใน v4.5 |
|---|---|---|
| P0 | ไม่พบตัวขวางการเปิดเกมในเส้นทางที่ตรวจ | Regression, stress และ Chrome campaign ผ่าน |
| P1 | จบรอบจากแท็บที่ถือสถิติเก่าแล้วทับสถิติที่อีกแท็บเพิ่งบันทึก | อ่านและรวมสถิติก่อนบันทึก เก็บฟอร์แมตเดิม และยังใช้ได้เมื่อพื้นที่จัดเก็บถูกปิด |
| P1 | Web Audio สร้าง gain หรือ oscillator ไม่สำเร็จแล้วเกมเข้า recovery | ยกเลิกเฉพาะเสียง รอบเกมและการควบคุมยังทำงาน ยืนยันว่าการเล่นตามปกติเปิด AudioContext ได้ และค่าปิดเสียงกับระดับเสียงอยู่ครบหลังโหลดใหม่ |

## ผลการทดสอบ

- Regression **85/85** ครอบคลุมการเข้าเกมครบสามโหมด อาวุธหกชนิด Perfect Parry, Dash, Active/Passive, AI, ไอเทม, ห้อง, No-Save และวงรอบเกม

- ตรวจ Pause/Resume 100, เปิด/ปิดกระเป๋า 100, เลือกรางวัล 100, ซื้อของ 100, เปลี่ยนภาษา 50, เฟส Frozen King 50 และหมุนจอ 58 ครั้ง รวม 50 ครั้งต่อเนื่อง ตรวจการคลิกซ้ำโดยไม่รับไอเทมหรือหักเงินซ้ำ [ผลหมุนจอ](visual/v45/rotation.json)

## ทดสอบซ้ำและส่งให้ทีม

จากโฟลเดอร์เกม ใช้ Node 24 และ Chrome กับ Playwright สำหรับชุดเบราว์เซอร์

```text
node --test --test-isolation=none tests/*.cjs
node --expose-gc tests/stress/run.cjs --extended
node tests/stress/balance.cjs .
node tests/browser/campaign.cjs . <output-dir>
node tests/browser/controls.cjs . <output-dir>
node tests/browser/landscape.cjs . <output-dir> --extended
node tests/browser/faults.cjs .
node tests/browser/visual.cjs . <output-dir> --profile-only
```

ทีมยังต้องรีวิว PR และทดสอบกับผู้เล่นจริง 3–8 คน ขอให้เก็บผลจาก iPhone Safari และ Android Chrome ตามรายการตรวจในคู่มือ คลิกเปิด Training และ Story ก่อนกรอกผล พร้อมระบุ seed เมื่อรายงานข้อบกพร่อง [คู่มือและแบบรายงานสำหรับทีม](https://tanapat1604-cmd.github.io/frostbound-v44-preview/playtest.html)

สาขา v4.5 ใช้ PR ซ้อนบน v4.4 เพื่อให้ทีมเห็นเฉพาะ diff ของรอบนี้ การอนุมัติเผยแพร่รุ่นเสถียรยังรอทีม พรีวิวใช้ไฟล์เล่นจริงจาก commit ที่ทดสอบ เก็บ commit v4.4 ในตารางฐานเพื่อย้อนพรีวิว และยังเปิด v4.2 ได้ผ่าน [เว็บเล่นรุ่นเสถียร](https://tanapat1604-cmd.github.io/frostbound-game/)
